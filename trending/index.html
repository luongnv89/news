Pick 1 · Developer tools / AI agents GitHub rank #13 of 16

Tracer-Cloud/opensre

Python · License: Apache-2.0

What it does. A command-line agent for broken CI builds and incidents: OpenSRE reads the failed run, traces the cause and pushes a fix for you to review, self-hosted and with your own models.

Why it is interesting — editorial. Material change since the 20 November card: on 22 November it merged a bridge that turns any MCP server's tools into agent tools, plus a guided setup command that connects to a server and lists its tools before saving it. A day earlier every built-in tool was made to declare its side effect, and below the shell's /auto high level the agent now asks before tools that write to outside systems.

Caveat. Still a public alpha, and the default /auto high level still runs outside writes without asking. A server's read-only flag is declared by the server itself, so the docs say to connect only trusted servers, and product analytics and Sentry error reports are opt-out.

Pick 2 · Video / content tools GitHub rank #16 of 16

zhouxiaoka/autoclip

Python · License: MIT

What it does. A desktop tool that turns long videos into short clips: AutoClip cuts clips with subtitles, covers and post text for Douyin, Xiaohongshu, TikTok, Reels, Shorts and other platforms, editing and rendering on your own computer.

Why it is interesting — editorial. Material change since the 20 November card: release v1.5.9, published late on 22 November UTC, reworks failure recovery and publishing and lowers the shortest subtitle highlight from 20 to 10 seconds. Its notes also change diagnostics: when no choice has been saved, failure diagnostics and a compressed clip of about 60 seconds from a local video upload automatically, kept for 14 days and not used for training, according to the notes.

Caveat. That upload default sits badly with the privacy policy, last updated 9 October, which says videos and audio are never uploaded to the project's servers; check the setting before cutting sensitive footage. The installers are unsigned, and on 23 November the app gained a CometAPI preset with the author's referral link and tracking of referral-link clicks.

Pick 3 · Developer tools / AI agents GitHub rank #9 of 16

cathrynlavery/diagram-design

HTML · License: MIT

What it does. An agent skill that draws diagrams: it writes one self-contained HTML and SVG file per diagram, in your own brand, for Claude Code, Codex, Cursor, Copilot and other hosts.

Why it is interesting — editorial. Material change since the 20 November card: on 23 November it added a Git graph type for branch, merge and release flows, with one lane per branch, merge commits drawn from two parents and tags as labels, plus a checker that refuses malformed graphs. The README now lists 52 diagram types, each in light, dark and full-editorial variants.

Caveat. This is a modest addition, and a graph is capped at 5 lanes and 16 commits. The checker tests the drawing's internal consistency, not whether it matches your real repository history, and diagrams still load Google Fonts unless you ask for system fonts.
