Pick 1 · Developer tools / browser automation GitHub rank #15 of 15

lightpanda-io/browser

Zig · License: AGPL-3.0

What it does. A headless browser written from scratch in Zig for scraping, testing and AI agents, not a Chromium or WebKit fork. It runs JavaScript with V8, parses HTML with html5ever and serves the Chrome DevTools Protocol and WebDriver BiDi, so existing Puppeteer or Playwright scripts can connect to it. It can also dump pages as HTML, Markdown or structured data, act as an MCP server with a separate browsing session per client, and run a built-in agent mode.

Why it is interesting — editorial. First time on our list. Headless Chrome is the default for automation but heavy at scale; Lightpanda drops graphical rendering altogether, and its README claims about 16 times less memory and 9 times faster runs than headless Chrome on 100 pages (the maintainers' benchmark on one AWS instance, not ours). The agent mode has a practical twist: prototype with a model, then save and replay a deterministic script that needs no model or tokens at runtime.

Caveat. Licensed AGPL-3.0, which matters if you offer it as a network service, and contributions require a CLA. Usage telemetry is on by default (LIGHTPANDA_DISABLE_TELEMETRY=true turns it off). It is not a full browser: with no rendering engine, PNG and PDF dumps are text-only, and web compatibility is tracked against Web Platform Tests rather than guaranteed. There is no native Windows or musl (Alpine) build, and the Homebrew and AUR packages track nightlies rather than the 1.0.2 release. We did not run it or its benchmark.

Pick 2 · Developer tools / AI agents GitHub rank #9 of 15

pingdotgg/t3code

TypeScript · License: MIT

What it does. An open-source control surface for the coding agents already on your machine: Claude Code, Codex, Cursor, Grok Build, OpenCode and Google Antigravity, through the subscriptions you already have. A local server runs the agents, and you drive them from a web app, an Electron desktop app or iOS and Android apps, connecting remotely through its T3 Connect tunnel, LAN pairing or Tailscale.

Why it is interesting — editorial. First time on our list. Rather than another agent, it is one interface over several, MIT-licensed so it can be forked. The practical draw is running agents on a desktop or server and steering them from a phone; devices pair through one-time links, and sessions can be listed and revoked. The FAQ is unusually frank, for example noting that Claude use through Anthropic's Agent SDK drains five-hour limits faster than Claude Code itself.

Caveat. The README says it is very early: expect bugs, and it is mostly not accepting contributions; most recent builds are nightlies and previews (latest stable v0.1.5, 29 October). Pairing a device gives it control of your machine's agents, so treat pairing links like keys. T3 Connect is free for up to three machines "for now", basic usage events (provider, model, token totals) are sent unless T3CODE_TELEMETRY_ENABLED=false, and the FAQ's tips on pooling several subscriptions come with its own warning that accounts could be banned. We did not install it.

Pick 3 · Developer tools / agent skills GitHub rank #8 of 15

mattpocock/skills

Shell · License: MIT

What it does. Matt Pocock's personal set of agent skills for engineering work, packaged as plugins for Claude Code, Codex and GitHub Copilot, or as editable files for Gemini CLI, Cursor, OpenCode and others. They cover alignment (grill-me, grill-with-docs), planning (to-spec, to-tickets, wayfinder), test-driven development, bug diagnosis, code review and architecture surveys, after a one-time setup that records your issue tracker, triage labels and docs location.

Why it is interesting — editorial. First time on our list, although it is one of the most-starred skill collections on GitHub. Unlike frameworks that own the whole process, these are small, composable skills meant to be edited, grounded in named classics such as The Pragmatic Programmer and Domain-Driven Design. Having the agent interview you before it writes code, and keeping a project glossary to cut its verbosity, are ideas worth borrowing even without installing anything.

Caveat. The plugin installs update themselves by default, so the instructions your agent follows can change without your review; the skills.sh route copies files you update by hand. Several skills write to your issue tracker and repo docs: v1.3.2 (29 October) fixed a template that had let agents working in clones of this repo file their tickets into it. It is one practitioner's workflow, opinions included, and the README also promotes his newsletter. We did not install it.

Pick 4 · AI agents / skills reference GitHub rank #11 of 15

anthropics/skills

Python · License: Mixed: Apache-2.0 and proprietary

What it does. Anthropic's public repository of Agent Skills: folders of instructions, scripts and resources that Claude loads for specialised tasks. It holds the Agent Skills specification, a template, and examples from art and design to MCP server building, web-app testing and the Claude API, plus the docx, pdf, pptx and xlsx skills that the README says power Claude's own document features. It can be added to Claude Code as a plugin marketplace.

Why it is interesting — editorial. First time on our list. It is the reference implementation of a format that several other projects on today's list also use, and the production document skills are readable examples of how complex skills are built. It is kept current: the mcp-builder skill was updated on 28 October to teach v2 of the MCP TypeScript SDK.

Caveat. Licensing is mixed: many skills are Apache-2.0, but the four document skills are source-available under Anthropic's terms, and their licence file forbids keeping copies outside Anthropic's services. GitHub detects no repository-wide licence. The README says the skills are for demonstration and educational purposes only and that Claude's built-in behaviour may differ. Skills include scripts an agent can run, so review them like code. We did not install them.
