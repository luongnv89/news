Pick 1 · AI agents / coding assistant GitHub rank #6 of 13

QwenLM/qwen-code

TypeScript · License: Apache-2.0

What it does. Qwen Code is an open-source AI coding agent for the terminal, with IDE plugins, a desktop app, a web UI, SDKs and chat integrations. The README lists memory, skills, sub-agents, agent teams and MCP support, and says it talks to OpenAI, Anthropic, Gemini and Qwen APIs as well as local models through Ollama or vLLM.

Why it is interesting — editorial. First time on our list. The 1.0 Preview, tagged on 11 November, merges the agent harness of Alibaba's Qoder with Qwen Code and ships native packages for macOS, Linux and Windows without a separate Node.js install. A regular v0.27.3 release followed overnight, so this is a fast-moving, multi-provider alternative to vendor-locked coding agents.

Caveat. The release notes say Preview interfaces, configuration and behaviour may change. The main install path pipes a remote script into a shell, and model calls go to whichever provider or account you configure, with that provider's costs and data terms. We did not install or run it.

Pick 2 · AI infrastructure / local inference GitHub rank #7 of 13

ashhart/TensorFold

Zig · License: Apache-2.0

What it does. TensorFold serves language models from a single Zig binary on Apple Silicon (Metal) and NVIDIA GPUs (CUDA). It reads checkpoints, tokenizes requests and runs its own kernels, and exposes OpenAI-style chat completions and Responses plus Anthropic Messages endpoints, with no Python or MLX install needed for serving.

Why it is interesting — editorial. First time on our list. It is a rare from-scratch inference engine in Zig rather than a wrapper around llama.cpp or MLX, with one local server that speaks both OpenAI and Anthropic APIs. Releases are frequent (v1.2.7 on 11 November), and the README documents pinned model revisions and checksum checks for its release archives.

Caveat. GitHub's listing mentions Vulkan, but the README documents only Metal and CUDA (CUDA 13, NVIDIA driver R580 or newer). The project is under five months old, its benchmarks are maintainer and community receipts rather than independent tests, model weights carry their own licenses, and its contributor tooling posts public check-ins to the maintainer's site.

Pick 3 · Developer tools / model routing proxy GitHub rank #12 of 13

Alishahryar1/free-claude-code

Python · License: AGPL-3.0-only

What it does. Free Claude Code is a local proxy that routes agent harnesses to other model providers. The README lists 12 clients, including Claude Code, Codex, OpenCode, Aider and VS Code Chat, and 61 providers, from free tiers such as NVIDIA NIM and OpenRouter to paid and local models, with retries, rate limits and provider fallback.

Why it is interesting — editorial. First time on our list. Despite the name, it does not hand out Anthropic's models: it keeps the Claude Code interface while swapping the model behind it, which shows how interchangeable agent harnesses have become. It also adds Discord and Telegram front ends with voice notes.

Caveat. The README states it is not affiliated with or endorsed by Anthropic, and free-tier limits are set by each provider and may change; the 1.3B-free-tokens figure and up-to-90% token savings are maintainer claims. Your code and prompts go to the routed provider through API keys you store in this proxy. AGPL-3.0 applies (GitHub's API shows no detected license; the LICENSE file says AGPL-3.0-only).

Pick 4 · AI infrastructure / local inference GitHub rank #13 of 13

ggml-org/llama.cpp

C++ · License: MIT

What it does. llama.cpp is the widely used C/C++ engine for running LLMs locally, on CPUs and most GPU backends, with a command-line tool and an OpenAI-compatible llama-server. It is the base layer under many desktop model runners.

Why it is interesting — editorial. First time on our list. Its v0.9.0 release on 4 November adds FP8 E4M3 quantization and a flash-attention-rows op for multi-sequence serving, four new model architectures including Mistral Large 4, and more speech models (Chatterbox TTS, Nemotron 3.5 Transcribe), plus ggml v0.29.0 with multi-node tensor parallelism.

Caveat. It is a mature project, so Trending here reflects attention rather than a new launch. Speed depends heavily on your hardware, backend and quantization, and the quick-start installer pipes a remote script into a shell; model weights come with their own licenses. We did not run it.

Pick 5 · Developer tools / version management GitHub rank #3 of 13

nvm-sh/nvm

Shell · License: MIT

What it does. nvm is a per-user, per-shell manager for multiple Node.js versions, written as a POSIX-compliant shell script. It installs, switches and aliases Node releases and reads a project's .nvmrc to pick the right one.

Why it is interesting — editorial. First time on our list. Version 0.41.0 (4 November) lets you select versions by category such as lts, non-lts or alpha, excludes alphas by default and records each version's LTS status, useful as agent CLIs such as Qwen Code now ask for Node.js 22 or newer.

Caveat. It works in POSIX shells on Unix, macOS and WSL; the README says native Windows is not supported beyond Git Bash or Cygwin in some cases. It loads from your shell startup files, installing means running a remote script, and where nodejs.org has no binary it compiles Node from source, which is slow and needs a C++ toolchain.

Pick 6 · Other / Apple Watch customization GitHub rank #4 of 13

pookjw/HermesEnabler

Objective-C · License: MIT

What it does. HermesEnabler 2 is a sideloaded watchOS app that enables Hermès watch faces on any Apple Watch. You install it from Xcode or a signed IPA, turn on Developer Mode on iPhone and Watch, and follow the steps in the app.

Why it is interesting — editorial. The day's standout outside AI and developer tooling, and first time on our list. It suggests these faces are gated by device configuration rather than hardware, and its README is unusually candid about install pitfalls; releases 1.5.3 and 1.5.4 both landed in the hours before our capture.

Caveat. Supported only on watchOS 27.0 through 27.3 beta 1. It changes system configuration (the README says to restore its MobileGestalt backup before deleting the app), needs sideloading and Developer Mode, may require a paid Apple developer team, and the author says use at your own risk.
