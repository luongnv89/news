Pick 1 · Productivity / team collaboration GitHub rank #5 of 14

macro-inc/macro

Rust · License: AGPL-3.0

What it does. An all-in-one team workspace that puts email, chat channels, tasks, collaborative Markdown docs, a canvas, recorded calls, file storage, linked pull requests and a CRM in one keyboard-first interface. Everything is @-linked in a shared graph, and a team-level AI memory, rebuilt nightly, is available to its own agent and to outside agents through MCP. It is built in Rust and SolidJS and offered as a hosted app with web, desktop and iOS clients, with the full source in this repository.

Why it is interesting — editorial. First time on our list. Instead of gluing Slack, Linear, Notion and a CRM together with automations, every item shares one backend, so a task stays linked to the email or message that created it and issue tracking happens where the conversation is. The makers call it fully open source rather than open core, under the AGPL-3.0, and they ship several releases a day.

Caveat. The hosted app needs a Gmail or Google Workspace account, and its team memory is built from your email, messages and calls: a lot of sensitive data for one service. The documented local stack is a contributor setup, not a turnkey self-host: Postgres, Redis, Kafka, OpenSearch and more in Docker, with stubbed Google, GitHub and Stripe integrations, and the agent harness needs real Google OAuth. AGPL terms apply if you host a modified version for others. Security certifications are the company's claims. We did not install or test it.

Pick 2 · Mobile development / AI coding GitHub rank #12 of 14

expo/skills

Shell · License: MIT

What it does. Expo's official agent skills for Expo and React Native apps: 24 SKILL.md guides listed in the README, covering Expo Router navigation, native UI and animation, data fetching, native modules, SDK upgrades and moving a web app to native, plus a separate group for the paid Expo Application Services (store builds and submission, over-the-air updates, hosting, workflows and observability). It installs as a Claude Code or Codex plugin, or through the skills CLI for Cursor, OpenCode and other agents.

Why it is interesting — editorial. First time on our list. Coding agents often reach for outdated React Native patterns; these guides come from the framework's own team, which keeps Expo's documentation and CLIs as the source of truth. The README separates free framework skills from paid services, and each services skill opens with a costs and plan-limits note, so you can see when an agent's advice leads to a paid plan.

Caveat. Useful only for Expo and React Native projects, and the services group assumes paid Expo Application Services. The Claude Code and Codex plugins also wire up Expo's MCP server, which can trigger builds and read crash data, and every skill tells the agent how to send feedback through an npx command that fetches Expo's agent CLI, so review what your agent may run. The skills are guidance, not tests of your app. We did not install or test them.

Pick 3 · Hardware / sensing / smart home GitHub rank #13 of 14

ruvnet/RuView

Rust · License: MIT

What it does. A WiFi sensing platform that reads Channel State Information from low-cost ESP32-S3 boards to detect presence and movement, estimate breathing and heart rate, recognise activities and falls, and pass those states to Home Assistant, Matter, Apple Home and local automations, without cameras. It ships Rust firmware and services, a Python package, pretrained models on Hugging Face and a Docker demo that runs on simulated data.

Why it is interesting — editorial. First time on our list. Camera-free room sensing is an active research field, and this is one of the most complete open toolkits for trying it on inexpensive hardware. Unusually, the README grades its own models: it retracted an earlier 100 percent presence figure in favour of 82.3 percent held-out accuracy, and labels its on-device pose model weak, below target and not yet wired in.

Caveat. Real sensing needs ESP32-S3 or other CSI-capable hardware; the Docker image uses simulated data, and ordinary laptops give presence only. The README calls it beta software, and its health uses are research prototypes, not medical devices. Accuracy figures are the maintainer's own, sensing people through walls raises consent and privacy questions, and the README also promotes the maker's roughly 140-dollar Cognitum Seed hub and an affiliate programme. We did not install it or download its models.

Pick 4 · Education / programming GitHub rank #14 of 14

xiaolai/the-craft-of-selfteaching

Jupyter Notebook · License: CC BY-NC-ND 3.0 (stated in README)

What it does. Li Xiaolai's free Chinese-language book on teaching yourself, using Python programming as the way in. It is a book written as Jupyter notebooks: chapters on deliberate practice, coping with material full of forward references and avoiding focus drift alternate with a Python primer on values, control flow, functions, strings, files, classes, regular expressions and test-driven development. A Markdown version reads without Jupyter.

Why it is interesting — editorial. First time on our list. Its argument, that the ability to teach yourself matters more than any single skill, fits a moment when tools change monthly, and it teaches the habit by example: read the official documentation, live with not understanding everything yet, and practise deliberately. Small fixes for current JupyterLab landed in May 2026.

Caveat. Chinese only. GitHub detects no license; the README states CC BY-NC-ND 3.0, so you may share it non-commercially with credit but not distribute adaptations or translations. The Python chapters were written in 2019 with only small fixes since, so some details may be dated. It is a book, not a tool, and we did not run its notebooks.
