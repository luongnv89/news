Pick 1 · AI / machine learning education GitHub rank #14 of 15

jingyaogong/minimind

Python · License: Apache-2.0

What it does. A from-scratch course in building a small language model: native PyTorch code and open data for every stage, from tokenizer and pretraining through fine-tuning, DPO, GRPO-style reinforcement learning and distillation, ending in a 64M-parameter chat model.

Why it is interesting — editorial. Most LLM tooling hides training behind a few library calls, while MiniMind writes the core algorithms out in plain PyTorch so each step can be read and changed. Its models stay compatible with transformers, llama.cpp, vLLM and Ollama, and the README puts the smallest one at about 1/2700 the size of GPT-3.

Caveat. The headline two hours is, by the README's own note, one epoch of the SFT stage on a single NVIDIA 3090, not the whole pipeline, and the RMB 3 figure is the matching GPU rental cost; both are maintainer claims. A 64M model is a teaching tool, not a capable assistant, and the main README is in Chinese with an English translation.

Pick 2 · Developer tools / AI agent plugins GitHub rank #8 of 15

cursor/plugins

TypeScript · No license detected

What it does. Cursor's official plugin repository: the plugin specification plus first-party and partner plugins that bundle agent skills, rules and MCP server definitions, from code-review and orchestration helpers to Gmail, GitHub and Salesforce connectors.

Why it is interesting — editorial. It shows how a major AI editor packages agent extensions: each plugin is a folder with its own manifest, skills, rules and MCP definitions, and the root marketplace manifest listed 149 plugins at our check. Cursor's own plugins, such as Thermos for branch security and correctness review and Orchestrate for fanning work out to parallel cloud agents, show the format in use.

Caveat. GitHub detects no license for the repository: the README ends with an MIT line and the plugin folders we sampled carry an MIT LICENSE file, but there is no root license, so check each plugin. Connector plugins give an agent access to mail, documents and business data under your account, so review their scopes first. There are no releases or version tags.

Pick 3 · AI agents / software delivery GitHub rank #4 of 15

Tencent/LoopForge

Go · License: MIT

What it does. A self-hosted workspace from Tencent for shipping software with coding agents: a chat bot opens Docker sandboxes with your repositories, delegates to project roles and opens pull requests, and proven workflows become SOPs of agent, script and human-approval steps.

Why it is interesting — editorial. Back three days after our 15 November card because version 0.4.0 (17 November) is a security-relevant release: its notes list keeping credentials out of repository clone URLs, confining agent CLI config writes to the home directory, and redacting agent CLI keys in SOP sandboxes. It also adds SSH repositories with per-host user keys and editing a run's workspace while agents work.

Caveat. It is still pre-1.0 software: 0.3.9 will never get a final release, and existing installations must apply new database migrations themselves. It runs as a Docker stack with MySQL, each executor needs its own model credentials, and the security fixes are the maintainers' description, not something we audited.

Pick 4 · AI coding / developer workflow GitHub rank #9 of 15

obra/superpowers

Shell · License: MIT

What it does. An agentic skills framework and development method for coding agents: a library of skills that walks an agent through brainstorming, planning, test-driven implementation and review, installed separately for Claude Code, Codex, Cursor, Copilot CLI and other harnesses.

Why it is interesting — editorial. Back on our list after our 28 October card because v7.0.2 (3 November) changes how brainstorming asks questions: it asks only when the answer would change what gets built, asks why first, and offers options with a recommendation. The same release fixes the start-up bootstrap for Copilot on Windows and in Pi, where a bug made prompt caching rewrite the whole conversation on the second prompt.

Caveat. The blind-graded improvement figures come from the maintainers' own test scenarios, not an independent benchmark. It works by adding session-start hooks and persistent instructions to your agent, so review what each harness install changes; the optional visual companion has telemetry you can switch off.

Pick 5 · Web development / frontend framework GitHub rank #12 of 15

sveltejs/svelte

JavaScript · License: MIT

What it does. A compiler-based UI framework: Svelte turns declarative components into JavaScript that updates the DOM directly, and is developed by volunteers under the MIT license.

Why it is interesting — editorial. Version 5.58.0 was published at 06:54 UTC today, after we passed on Svelte yesterday for lack of news. It is a minor release that gives Svelte devtools the component instance and snippet name behind rendered elements, with patch notes that speed up server rendering of pages with many or deeply nested components and fix several hydration bugs.

Caveat. This is an incremental release, not a new major version: the two features target devtools and dev-mode metadata, and the performance notes carry no figures. GitHub does not say why a project is trending, and nothing shown ties today's attention to this release.
