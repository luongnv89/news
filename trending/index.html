Pick 1 · Security / AI agents GitHub rank #1 of 16

elementalsouls/Claude-BugHunter

Python · License: MIT

What it does. A skill bundle for authorized bug hunting and external red-team work: 85 skills and 16 slash commands for Claude Code, built from patterns in 681 disclosed HackerOne reports, with an engine meant to keep each test inside the program's scope.

Why it is interesting — editorial. Material change since the 24 November card, which reported its scope gate hardened against three fail-open paths: on 25 November it closed another path out of scope, reported through responsible disclosure. According to the pull request, a backslash in a URL's host part let the scope check see an in-scope host while the HTTP client connected to a different, out-of-scope one, which could reach excluded, loopback or local-network hosts. The same fix stops full AWS secret keys and session tokens being written in the clear to the local state file, and a new cbh diff command re-tests a target for only what changed since the last run.

Caveat. This is offensive tooling, for assets you own or are authorized to test. Two scope-gate fixes in three days make the gate a backstop, not a guarantee: an earlier pull request says it guards only the engine and the /scope command, the Medium severity rating is the maintainer's own, and there is still no tagged release since v2.1 of June, so the fixes sit only on the main branch.

Pick 2 · Desktop utilities / Downloads GitHub rank #15 of 16

XiaoYouChR/Ghost-Downloader-3

Python · License: GPL-3.0

What it does. A cross-platform download manager for Windows, macOS, Linux and Android: one app handles HTTP, BitTorrent, FTP, M3U8 and DASH streams, with a browser extension, a ghd command line and an aria2-compatible RPC API for other tools.

Why it is interesting — editorial. Material change since the 21 November card: version 4.6, released on 25 November, ships what had sat unreleased on the main branch. Linux gets in-app updates (except for the AppImage) and a one-line install script, Android gets incremental updates, scheduled tasks can now quit the app, and the BitTorrent pack can fetch just the .torrent file without parsing it. The release notes also claim faster startup and lower memory use.

Caveat. Linux releases no longer include a .deb package; the notes point to the install script, AppImage or .tar.xz instead, and an in-app updater means trusting the maintainer's update channel. The README still promotes real-browser TLS fingerprints to slip past anti-bot checks and a paid residential-proxy sponsor, YouTube and Bilibili downloads can conflict with those sites' terms and with copyright, and the maintainer says updates will slow down.

Pick 3 · AI video / Creator tools GitHub rank #16 of 16

zhouxiaoka/autoclip

Python · License: MIT

What it does. An open-source AI video-clipping desktop app: it cuts long podcasts, interviews, courses and stream replays into short clips with captions, covers and post copy for TikTok, Shorts, Reels, Douyin and Xiaohongshu.

Why it is interesting — editorial. Material change since the 23 November card: two releases in two days. Version 1.6.0 (24 November) adds a Live Replay tab that imports stream recordings from OBS Studio, Twitch, YouTube, Kick and Discord, or local files, with a reworked game-highlight engine; version 1.6.1 (25 November) adds importable template packs and custom HTTP headers and reasoning-effort settings for OpenAI-compatible model providers.

Caveat. Version 1.6.1 lets the app's provider list change from a signed cloud catalogue without a new release, and a 23 November pull request did the same for sponsor promotions, so what the settings recommend can shift remotely. The privacy policy lists anonymous usage analytics as currently enabled, with an off switch, the installers are unsigned, and clipping someone else's stream needs the rights to it.
