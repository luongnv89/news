Pick 1 · Security / programming languages GitHub rank #1 of 9

php/php-src

C · License: BSD-3-Clause

What it does. The source code of the PHP interpreter itself, the language runtime behind a large share of web servers, including PHP-FPM, Apache mod_php and php-cgi deployments.

Why it is interesting — editorial. First time on our list, and the most urgent card this week. On 21 October the PHP project released 8.5.12, 8.4.27, 8.3.36 and 8.2.35 to fix two critical vulnerabilities (CVE-2026-109618 and CVE-2026-109619) that its advisory says can allow unauthenticated remote code execution. The advisory names every installation serving web requests as at risk, rates mod_php highest with a demonstrated exploit that fires before any application code runs, and says updating is the only complete fix.

Caveat. If you run PHP, check your version and your distribution or vendor packages rather than this repository: Linux distributions and LTS vendors received the patches in advance, and PHP 8.1 and older get no official releases from the project. The interim php.ini mitigations in the advisory reduce exposure to specific attack paths but explicitly do not make an installation safe. PHP 8.2 reaches end of life on 31 December 2026. We relied on the project's own advisory and did not test the flaws.

Pick 2 · Developer tools / web frameworks GitHub rank #7 of 9

fastapi/fastapi

Python · License: MIT

What it does. A Python web framework for building APIs from standard type hints, with automatic request validation through Pydantic and generated OpenAPI documentation.

Why it is interesting — editorial. First time on our list. FastAPI is a mature, widely used choice for Python APIs, and its maintainers shipped four releases between 21 and 22 October. Release 0.160.0 is the one to read before upgrading: query, header, cookie and form parameter models now apply their extra setting to every field in the same location, so a model with extra="forbid" now rejects fields declared elsewhere. 0.159.1 and 0.161.0 add support for optional and combined unions of form models.

Caveat. FastAPI is still versioned 0.x, and 0.160.0 is labelled a breaking change inside a minor version bump, so pin the version and run your tests before upgrading; requests that used to pass may now be rejected. The "high performance" wording is the project's own claim and depends on your server, database and workload.

Pick 3 · Games / desktop software GitHub rank #9 of 9

Meloong-Git/PCL

Visual Basic .NET · License: Custom source-available license (see LICENCE)

What it does. Plain Craft Launcher (PCL), a popular Chinese-language desktop launcher for Minecraft Java Edition. The repository holds most of its source, including its UI library, animation, download and game-launch modules.

Why it is interesting — editorial. First time on our list, and a change from developer and AI tooling. It is also a clear example of a source-available project: the code is public and its guide explains in plain language what light reuse (credit is enough) and heavy reuse (naming, attribution and disclosure rules) look like, rather than granting an open-source license.

Caveat. Not open source. GitHub detects no standard license; the LICENCE file points to a custom limited distribution license hosted on an external document site and adds a usage guide, and the developer reserves all other rights. Heavier reuse carries naming, attribution, source-publication and sponsor-prompt conditions. The README says code is synced only when PCL releases, so it can lag the shipping app. Documentation is in Chinese. The repository also contains a prebuilt zip, which we did not inspect or run.

Pick 4 · AI agents / documentation GitHub rank #8 of 9

luongnv89/claude-howto

Python · License: MIT

What it does. A visual, example-driven guide to Anthropic's Claude Code, with a learning path from first prompts to slash commands, memory, hooks, skills, MCP servers and subagents, plus copy-paste templates. Translated into Vietnamese, Chinese, Ukrainian and Japanese.

Why it is interesting — editorial. First time on our list. Disclosure: this repository is maintained by the publisher of this newspaper. It is useful for teams adopting Claude Code because it shows how the features combine into workflows, not just what each one does, and it tracks the tool closely: commits on 19 October synced it to Claude Code v2.1.302, and a 20 October change made the database MCP example read-only by default.

Caveat. It is a third-party guide, not Anthropic documentation, and Claude Code changes quickly, so check details against the official docs. Hook, MCP and agent templates can run commands or give an assistant access to systems, so review permissions before copying them into a project. The last tagged release is from June; updates arrive as commits.
