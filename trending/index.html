Pick 1 · AI agents / engineering workflow GitHub rank #3 of 12

addyosmani/agent-skills

JavaScript · License: MIT

What it does. Agent Skills is a pack of 25 plain-Markdown engineering skills for AI coding agents, written by Addy Osmani. Nine slash commands follow a spec, plan, build, test, review and ship lifecycle, and the README gives install paths for Claude Code, Cursor, Codex, Gemini CLI, Copilot and other hosts.

Why it is interesting — editorial. First time on our list. Rather than prompts, it packages senior-engineer habits as enforceable steps: spec before code, small test-driven tasks, a five-axis review before merge. Release 0.6.15 (31 October) stopped its staged-secret check from printing the secrets it finds and made the security and accessibility gates actually fail CI.

Caveat. Skills and hooks steer an agent that can edit code and run commands, so read what you install; 0.6.15 itself fixed a check that leaked secrets into transcripts and a hook that could corrupt protected code. A per-skill install omits the shared reference checklists, and the README's /build auto mode runs every task after one plan approval, pausing only on failures or risky steps. We did not install it.

Pick 2 · Developer tools / web framework GitHub rank #10 of 12

tokio-rs/topcoat

Rust · License: MIT

What it does. Topcoat is a batteries-included full-stack web framework for Rust from the Tokio organisation. Pages and components are async Rust functions rendered on the server, with an HTML-like view! macro, module-based routing, an asset bundler, Tailwind support and an editable component library copied into your project.

Why it is interesting — editorial. First time on our list. Its distinctive trick: a $(...) expression is type-checked Rust that also runs as JavaScript in the browser, so small interactions need no server round trip, no WebAssembly bundle and no client build step. v0.12.0 (9 November) unified its context model and v0.12.1 (10 November) added OpenAPI generation.

Caveat. The README says it is early-stage and experimental; expect breaking changes, and v0.12.0's own notes say most apps need many small edits to upgrade. Static export, validations and more reactivity are still roadmap items, so it is a framework to evaluate rather than to bet production on yet. We did not install it.

Pick 3 · Self-hosted apps / personal finance GitHub rank #6 of 12

we-promise/sure

Ruby · License: AGPL-3.0

What it does. Sure is a self-hostable personal finance and net-worth app, a community fork of the abandoned Maybe Finance project. It is a Ruby app that self-hosts with Docker alongside PostgreSQL and Redis, and the README lists a browser, a macOS desktop app, a mobile app, API clients and LLM agents as ways in.

Why it is interesting — editorial. First time on our list. It is a rescued codebase with active community upkeep: Maybe's team stopped in 2023 after, by their account, nearly a million dollars of work, and Sure keeps shipping. The 10 November nightly added a Monarch importer, account statements in the API and a fix that refuses another family's categories in the API.

Caveat. You hold your own financial data, so backups, updates and access control are on you. The optional AI features need an OpenAI token or an external assistant, which then receives the questions and data you send it. Nightly tags are alpha builds with debug mobile apps, the latest stable is v0.7.6 (31 October), and AGPL-3.0 applies to anyone serving a modified version. We did not install it.

GitHub Trending is an editorial digest of GitHub’s public daily Trending page, published with The AI Gazette. Picks are listed in curation order, not GitHub’s rank; each card shows the rank GitHub displayed when the page was checked. Stars measure attention, not security, quality or fitness for use, and no project here was installed or run. “Stars today” is GitHub’s own displayed figure for its daily window, not an audited rolling 24-hour count. Every figure and link is shown with the time it was checked.

Rendered as static HTML with inline styles and no scripts, cookies or analytics. Typefaces are requested from Google Fonts (fonts.googleapis.com, fonts.gstatic.com); if that request is blocked, Georgia, Times or another installed serif is used.
