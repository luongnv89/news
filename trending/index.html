Pick 1 · Developer tools / cloud testing GitHub rank #8 of 13

floci-io/floci

Java · License: MIT

What it does. A free local emulator of AWS services for development, tests and CI. You point the AWS CLI, an SDK, Terraform, CDK or OpenTofu at localhost:4566 and work against S3, DynamoDB, SQS, Lambda, IAM and well over a hundred other service names without a cloud account or auth token. Lambda, RDS, ECS, EKS, OpenSearch and a few others run in real Docker containers rather than shallow mocks, and a browser console shows the local resources.

Why it is interesting — editorial. First time on our list. The README presents it as a drop-in replacement for LocalStack Community, which it says now needs an auth token: the same port, translated LocalStack environment variables, unchanged init scripts and a Testcontainers-compatible ready line. It is MIT-licensed, ships a Docker image and a standalone binary, and releases often; 2.4.0 (31 October) added many API Gateway and Auto Scaling operations.

Caveat. An emulator is not AWS: behaviour and permissions can differ from the real service, so check the per-operation coverage page and keep tests against real AWS for anything that matters. By default any credentials are accepted, and the console and container-backed services need the Docker socket, which gives the emulator control of your Docker host. The startup, memory and image-size comparisons are the maintainers' own figures. The project dates from February 2026. We did not run it.

Pick 2 · Productivity / speech-to-text GitHub rank #10 of 13

anomalyco/hex

Rust · License: MIT

What it does. A push-to-talk dictation app for macOS, Windows and Linux: hold a shortcut, speak, let go, and the text is transcribed on your device and pasted into the app you are in. You can pick among several local speech models, add your own model files, keep a vocabulary of names per mode, and use opt-in meeting transcription. A command-line tool lets coding agents read retained transcripts and control the running app.

Why it is interesting — editorial. First time on our list. We passed on it on 2 November because it overlapped Handy, the local dictation app we picked that day; since then v3.3.0 (2 November) added a side-by-side model picker, per-mode vocabularies and a Russian model. Its difference from Handy is the agent side: transcripts and app control from the command line, and an Annotate mode that records your screen while you talk and sends it to an agent.

Caveat. The README says nothing leaves your machine after the first speech-model download; that is the maintainers' claim, not something we tested. The macOS build needs Apple silicon and macOS 15, and Windows and Linux are labelled beta. Its security notes say custom command handlers and npm dependencies run with your permissions and are not sandboxed. Unfinished features sit in a Labs switch that is on by default, releases arrive several times a day, and the project does not take pull requests. We did not install it.

Pick 3 · AI agents / internal developer platforms GitHub rank #7 of 13

spotify/portal-ai-plugins

TypeScript · License: Apache-2.0

What it does. Spotify's official plugins that bring its Spotify Portal developer platform into coding agents (Claude Code, Codex, Cursor and pi). They wrap the Portal CLI in eleven workflows: search the software catalog and documentation in plain language, write a short briefing on a service's owners, health and incidents, run Portal actions with dry-run and confirmation steps, and create, run and check Fleetshift fleet-wide code changes that open pull requests.

Why it is interesting — editorial. First time on our list. It is a worked example of giving agents an organisation's service catalog as context instead of letting them guess who owns what, and the actions workflow builds in previews and confirmations before anything changes. A second plugin, shunt, sends bulk file reads and boilerplate to cheaper models through Portal's AiKA assistant; the maintainers claim 82-94% token savings, which we did not verify.

Caveat. It is only useful if your organisation pays for Spotify Portal, a commercial product sold through its sales team and AWS Marketplace. Shunt installs hooks that stop Claude reading large files and sends that content to your Portal instance instead, so check what your company allows. The repository has no releases, its last commit was 23 October, and the setup runs the Portal CLI from npm. Apache-2.0. We did not install it.

Pick 4 · AI automation / marketplace monitoring GitHub rank #9 of 13

Usagi-org/ai-goofish-monitor

Python · License: MIT

What it does. A self-hosted monitor for Xianyu (Goofish), Alibaba's second-hand marketplace, with a web dashboard. You create watch tasks with keywords, price ranges, region and posting-time filters, either by hand or by describing what you want in plain language; a Playwright browser searches on a schedule, a vision-capable AI model judges each new listing from its text and photos, and matches are pushed to ntfy, Bark, Telegram, WeChat Work or a webhook.

Why it is interesting — editorial. First time on our list. It is a complete, practical example of an AI model used as a shopping filter: the model writes the judging criteria from your request, then scores listings against them, and the results, price history and logs live in SQLite behind a FastAPI web interface. It runs in one Docker container with Chromium included, and there is an English README.

Caveat. It logs in with your Xianyu session cookies, exported through a third-party Chrome extension, and rotates accounts and proxies when the site's risk controls trigger. The README itself asks users to respect Xianyu's terms and avoid frequent requests, and accounts can be restricted. Every listing's photos go to the AI provider you configure, at your cost. The web login defaults to admin/admin123, and v2.5 (9 October) fixed a path-traversal bug. No commits since 10 October. We did not run it.

Picks are listed in curation order, not GitHub’s rank; each card shows the rank GitHub displayed when the page was checked. Stars measure attention, not security, quality or fitness for use, and no project here was installed or run. “Stars today” is GitHub’s own displayed figure for its daily window, not an audited rolling 24-hour count. Every figure and link is shown with the time it was checked.

Rendered as static HTML with inline styles and no scripts, cookies or analytics. Typefaces are requested from Google Fonts (fonts.googleapis.com, fonts.gstatic.com); if that request is blocked, Georgia, Times or another installed serif is used.
