## Picks

### 1. [NVIDIA/SkillSpector](<https://github.com/NVIDIA/SkillSpector>)

*Security / AI agents · GitHub rank #7 of 14 · Python · License: Apache-2.0*

**What it does:** A **security scanner for AI agent skills** (Claude Code, Codex, MCP and similar). It scans a folder, single SKILL.md, Git repository, URL or zip file against 71 patterns in 17 categories, including prompt injection, data exfiltration, privilege escalation, supply-chain and memory-poisoning risks, with an optional LLM second pass, and reports a 0-100 risk score as terminal, JSON, Markdown or SARIF output.

**Why it is interesting (editorial):** *First time on our list. Agent skills run with broad trust and little vetting, and this gives a **repeatable pre-install check** you can wire into CI via SARIF, with a baseline file so re-scans show only new findings. It is part of NVIDIA's own pipeline for signing skills in its catalog. The v2.13.0 release on 16 October disabled the Codex CLI analysis provider because its sandbox could read host secrets, and v2.13.1 followed on 23 October with false-positive fixes.*

**Caveat:** A scanner lowers risk but **cannot prove a skill is safe**: static patterns miss novel tricks and flag harmless text, and the README's figure that 26.1% of 31,132 analysed skills had vulnerabilities is the project's own research. The optional LLM pass sends skill content to the provider you configure and uses your API credits. Requires Python 3.12+ or Docker, and installs further third-party packages. We did not install or test it.

### 2. [gitroomhq/postiz-app](<https://github.com/gitroomhq/postiz-app>)

*Productivity / social media · GitHub rank #12 of 14 · TypeScript · License: AGPL-3.0*

**What it does:** An **open-source social media scheduler** with a calendar, cross-posting, team collaboration, analytics, RSS auto-posting, AI writing and image tools, a public API and webhooks, plus MCP and CLI access so AI agents can draft and schedule posts. It runs as Postiz Cloud or self-hosted with Docker on your own Postgres and Redis.

**Why it is interesting (editorial):** *First time on our list. A mature project (created 2023) and a credible alternative to paid schedulers, with **no feature gating in the self-hosted edition**: unlimited channels, posts and team members, as its README compares. It also connects to automation tools such as n8n, Make and Zapier. Its two latest releases, v2.25.2 and v2.25.3 on 23-24 October, are security releases.*

**Caveat:** Both releases flag security advisories and ask **all users to upgrade immediately**; the commits name a JWT bypass and local-file access fix, so self-hosters must keep up with patches. Self-hosting also means creating your own developer apps on each social network, and Meta, YouTube or TikTok approval can take weeks. AI features need your own provider keys. AGPL-3.0 applies if you modify and serve it. We did not install or test it.

### 3. [nightly-labs/openbot](<https://github.com/nightly-labs/openbot>)

*AI agents / desktop · GitHub rank #9 of 14 · TypeScript · License: PolyForm Noncommercial 1.0.0*

**What it does:** A **desktop workspace for persistent AI teammates**: each agent, backed by Codex, Claude Code, Grok, OpenCode, Gemini, Cursor or Cline, gets its own workspace and conversation, with message queues, file transfers, agent-to-agent messaging, shared channel chats, an embedded browser agents can control, and optional computer use. Builds exist for macOS, Windows and Linux.

**Why it is interesting (editorial):** *First time on our list. Instead of juggling several agent CLIs in terminals, it runs them side by side as named teammates that can hand tasks to each other, with one task owner per shared chat and Stop, Resume and Reassign controls. It detects local model servers such as Ollama and LM Studio. Development is fast: v0.49 to v0.51.1 shipped between 24 and 26 October.*

**Caveat:** A development preview: agents run with **full access and no per-action approval** after first-launch consent, so they can change files, run commands and use the network unattended. It is source-available under PolyForm Noncommercial 1.0.0, **not an open-source license**: commercial use needs a paid license. Optional accounts use the maker's cloud service, and model costs are your providers'. We did not install or test it.

### 4. [Panniantong/Agent-Reach](<https://github.com/Panniantong/Agent-Reach>)

*AI agents / research tools · GitHub rank #10 of 14 · Python · License: MIT*

**What it does:** A command-line layer that **lets AI agents read platforms ordinary web search misses**: GitHub, YouTube subtitles and transcripts, Reddit, LinkedIn jobs, X, Bilibili, Xiaohongshu, V2EX, Xueqiu and podcasts, through one agent-reach command that picks a working tool for each site and falls back to another when one breaks.

**Why it is interesting (editorial):** *First time on our list. It packages a messy job, keeping scrapers for many sites working, behind one stable command any agent can call, and is strong on Chinese platforms that general search covers poorly. The v1.6.0 rebuild on 23 October keeps everything under one folder, uses its own background browser for login sites, and the README states it is read-only: it never posts, comments or sends messages.*

**Caveat:** Login channels **copy a site's login from your Chrome**, and platforms may restrict accounts used for automation; the README itself advises a secondary account. Some channels are labelled experimental and the 1.6.0 release shipped with several untested on the release machine (Reddit, Instagram, LinkedIn among them). Scraping may conflict with a site's terms. The PyPI package of the same name is not this project. We did not install or test it.

### 5. [alchaincyf/huashu-design](<https://github.com/alchaincyf/huashu-design>)

*AI agents / design · GitHub rank #13 of 14 · HTML · License: MIT*

**What it does:** An **HTML-native design skill** for Claude Code, Codex, Cursor and other agents: from one sentence it produces clickable app or web prototypes, HTML slide decks with editable PPTX export, timeline animations as MP4 or GIF, infographics and a five-point design review. Version 3.0 proposes six directions to pick three from and ships a library of 84 styles with samples.

**Why it is interesting (editorial):** *First time on our list. Unlike the design-taste skills we covered on 25 October, it **delivers finished files** (prototype, deck, video) rather than only rules, and it keeps a local record of the styles you choose so later results follow your taste. The README says the core render and export pipeline runs locally with no network or keys; cloud voice-over and review scripts are optional. It moved to the MIT license in May.*

**Caveat:** The main README and examples are in Chinese (an English README exists). The author calls it an 80-point skill: no layer-editable Figma output, no 3D or physics animation, and weaker results for a brand designed from scratch. The timings in its table are the author's claims. Older skills CLI versions install only SKILL.md and miss the scripts it needs. We did not install or test it.
