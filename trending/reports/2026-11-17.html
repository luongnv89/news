Pick 1 · Developer tools / self-hosting GitHub rank #6 of 15

getarcaneapp/arcane

Go · License: BSD-3-Clause

What it does. A self-hosted web interface for managing Docker: containers, images, volumes, Compose projects and remote hosts from one dashboard, written in Go.

Why it is interesting — editorial. Version 3.0.0, published on 14 November, redesigns the dashboard and expands GitOps and backups. The release notes also list live upgrade progress, update blocking based on image vulnerability scans, and renamed Arcane agents with mTLS enrollment for managing other hosts.

Caveat. Version 3 is a breaking upgrade: configuration variables gain an ARCANE_ prefix, legacy protocols, image tags and CLI flags are removed, and the polling agent is gone; the 2.x line lives on a separate branch. Like any Docker manager it needs the Docker daemon, which amounts to root access on the host.

Pick 2 · AI agents / media tools GitHub rank #15 of 15

kajisho5/ffmpeg-skill

Python · License: MIT

What it does. A local video editor for coding agents: 42 FFmpeg tools for cutting, captions, reframing, loudness and exports, packaged as an Agent Skill and an MCP server for Claude Code, Cursor and Codex.

Why it is interesting — editorial. It keeps footage on your machine, with no cloud service or API key, and each tool takes typed arguments rather than raw shell strings. The README says no tool runs a shell or accepts a caller-supplied filter graph, and that every edit is checked by measuring the output file.

Caveat. It does not ship FFmpeg, so it inherits the bugs and CVEs of whatever build you have installed; its own doctor command only warns. The safety design is the maintainer's description, not something we audited, and the main install path runs an npx package.

Pick 3 · Education / data visualisation GitHub rank #7 of 15

DeanChensj/jiangshan-map

JavaScript · License: GPL-3.0

What it does. An interactive historical atlas of China from 403 BCE to the present: drag a timeline to watch territories change across 18 periods, and click cities to see their names, events and poems through the ages.

Why it is interesting — editorial. It is a browser atlas that turns 2,400 years of history into a timeline, with an English interface, a live demo and an export script that writes standard GeoJSON for other mapping projects. The README names its sources and links a form for reporting data errors.

Caveat. The README says historical borders are schematic approximations, not surveyed boundaries, and the early first-level divisions have no recorded source. The prefecture layer derives from CHGIS and may not be redistributed or used commercially.

Pick 4 · AI research tools GitHub rank #12 of 15

google-research/paper-orchestra

Python · License: Apache-2.0

What it does. A multi-agent framework from Google Cloud AI Research that turns research notes and experiment logs into a LaTeX paper draft, with agents for the outline, literature review, section writing, refinement and plots.

Why it is interesting — editorial. It is the research code behind an arXiv preprint, so the pipeline can be read alongside its description, and it includes automated raters for evaluating the drafts. It works with Gemini or OpenAI models and conference LaTeX templates.

Caveat. The README calls it not an officially supported Google product, and the dataset used in the paper is not included yet. Running it needs paid model API keys plus a Semantic Scholar key, and a generated draft still needs authors to check every citation and claim.

Pick 5 · AI agents / research GitHub rank #9 of 15

mvanhorn/last30days-skill

Python · License: MIT

What it does. An agent skill that researches a topic across Reddit, Hacker News, GitHub, YouTube, prediction markets and the web, scores what people engaged with over the last 30 days, and writes a grounded brief.

Why it is interesting — editorial. It searches discussion rather than editorial pages, and it shipped three releases in about 16 hours on 16 November (UTC), ending at v4.3.0. Disclosure: an earlier version of this engine powers part of The AI Gazette's own research step.

Caveat. The wider sources rely on your own API keys or browser sessions, which gives an agent access to those accounts. Upvotes and market odds measure attention, not truth, and Polymarket is restricted in some countries, including France.
