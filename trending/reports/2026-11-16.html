Pick 1 · Machine learning infrastructure GitHub rank #8 of 12

ggml-org/ggml

C++ · License: MIT

What it does. The tensor library behind llama.cpp: plain C/C++ with no dependencies, it runs machine-learning models on CPUs, GPUs, NPUs and in the browser, with 2- to 8-bit quantization and the GGUF file format.

Why it is interesting — editorial. Version 1.0.0, published on 13 November, marks the first major version of the engine behind local AI. It prunes the deprecated public API, adds FP8 support and configurable YaRN truncation, and lists broad backend work across CUDA, Metal, Vulkan, SYCL, OpenCL and WebGPU. Speed gains in the release notes are maintainer claims.

Caveat. 1.0.0 is a breaking release for anyone on the old API: deprecated functions and the legacy DIAG_MASK ops are gone, and the RPC protocol bump rejects older peers. Core changes are made in the llama.cpp repository and synced here, so issues and pull requests belong there.

Pick 2 · AI agents / evaluation GitHub rank #12 of 12

NVIDIA/SkillEvaluator

Python · License: Apache-2.0

What it does. A test bench for AI agent skills from NVIDIA: it checks a skill folder for safety and format, flags duplicated guidance, then runs an agent with and without the skill in a sandbox to measure whether it helps.

Why it is interesting — editorial. Skill libraries are multiplying fast, and this asks the useful question: does the skill actually change the result? Its Skill Lift score compares runs against a no-skill baseline, and version 0.9.0 adds spending budgets, version comparisons and reports that show which expectations were met or left unchecked.

Caveat. NVIDIA labels it experimental, with community best-effort support and no SLA. Static checks run without a model, but full checks fetch extra security scanners, and live evaluation needs a model provider, a supported agent and Docker; model and sandbox use can cost money.

Pick 3 · Security / AI agents GitHub rank #9 of 12

elementalsouls/Claude-BugHunter

Python · License: MIT

What it does. A skill bundle for authorized bug hunting and external red-team work: 83 skills and 15 slash commands for Claude Code, also loadable by other agents, covering recon, web vulnerability classes, enterprise platform attack chains, validation and report writing.

Why it is interesting — editorial. Instead of one generic security prompt, it splits the work into per-class skills built from 681 disclosed HackerOne reports, with a scope and validation gate before anything is submitted. The README is explicit about what it leaves out, such as internal Active Directory attacks, C2 and evasion.

Caveat. This is offensive tooling, for assets you own or are authorized to test. It is a single maintainer's project with commercial sponsors, its 'battle-tested' claims are unverified, and the copy installer writes into the skill folders of several agents and can wire in a Burp MCP server.

Pick 4 · AI agents / design tools GitHub rank #3 of 12

google-labs-code/stitch-skills

TypeScript · License: Apache-2.0

What it does. Agent skills for Google Stitch, an AI design tool: they let a coding agent generate and edit screens, extract a DESIGN.md from existing code, and turn Stitch designs into React, React Native or shadcn/ui components.

Why it is interesting — editorial. It joins design and code in one agent loop: code goes up into Stitch as designs, and designs come back as components. The skills follow the open Agent Skills format, so the same folders work in Codex, Claude Code, Cursor, Gemini CLI and, with manual setup, OpenCode.

Caveat. Every skill needs the Stitch MCP server and a Stitch account, so design data goes to Google's service. The README says it is not an officially supported Google product, and the repository's last push was on 17 August.
