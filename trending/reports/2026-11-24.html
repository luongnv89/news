Pick 1 · Infrastructure / Security GitHub rank #7 of 16

nginx/nginx

C · License: BSD-2-Clause

What it does. The official NGINX web server and reverse proxy: releases 1.31.10 (mainline) and 1.30.8 (stable), both published on 23 November, fix excessive CPU usage with TLS 1.3 early data (CVE-2026-132779).

Why it is interesting — editorial. Material change since the 20 November card, which covered the ten fixes in 1.31.9 and 1.30.7: five days later nginx shipped another security release. nginx.org's advisories page rates the new flaw medium and lists every version from 1.21.4 to 1.31.9 as vulnerable. The same releases also fix nginx hogging CPU when SSL connections to backends are used.

Caveat. The CHANGES file ties the flaw to the ssl_early_data directive, so check whether your configuration uses it before treating this as urgent. No exploit details were checked here, and distribution packages may ship the fix under different version numbers than upstream.

Pick 2 · Security / AI agents GitHub rank #1 of 16

elementalsouls/Claude-BugHunter

Python · License: MIT

What it does. A skill bundle for authorized bug hunting and external red-team work: 84 skills and 15 slash commands for Claude Code, built from patterns in 681 disclosed HackerOne reports.

Why it is interesting — editorial. Material change since the 22 November card: on 23 November it hardened its scope gate against three fail-open paths that users reported, so pasted rules with schemes, ports or paths, IPv6 ranges and redirects to out-of-scope hosts no longer slip through. A new cbh scope import command fills the scope file from a program's published scope, and since 24 November a default run no longer stores target hostnames and URLs across engagements.

Caveat. This is offensive tooling, for assets you own or are authorized to test. The pull request says the scope gate guards only the engine and the /scope command, not the plain skill path; public program scopes come from a third-party hourly dump, bounty-targets-data, so check them against the program page. There is still no tagged release since v2.1 of June.

Pick 3 · AI agents / Web data GitHub rank #6 of 16

firecrawl/firecrawl

TypeScript · License: AGPL-3.0

What it does. A web scraping and crawling service for AI agents: it turns websites into clean Markdown as a hosted API, a self-hosted server or the single-binary Firecrawl Local.

Why it is interesting — editorial. Material change since the 20 November card: on 23 November it removed the FIRE-1 smart-scrape agent. Requests that still set the agent option on v1 scrape, or ask for FIRE-1 on extract, now fail with a 400 error before any job is queued, and the message points to /v2/agent or a json format on /v2/scrape. The self-hosted search path now also filters SearXNG and DuckDuckGo results against includeDomains and excludeDomains, so off-domain results stop leaking in.

Caveat. Code that still sends the agent option will get errors instead of results and needs updating; when the hosted service runs this code was not checked. The project is mainly AGPL-3.0, with MIT SDKs, and a new opt-in header that keeps personal emails and phone numbers out of data-provider results depends on a provider-side change the pull request calls separate.

Pick 4 · AI inference / Developer tools GitHub rank #8 of 16

openvinotoolkit/openvino

C++ · License: Apache-2.0

What it does. Intel's open-source inference toolkit: it converts and optimizes trained models and runs them on CPUs, Intel GPUs and Intel NPUs.

Why it is interesting — editorial. Material change since the 21 November card: on 23 November it merged native GGUF conversion for seven more model families: Cohere2 (Command R7B), Gemma3n with its vision projector, Qwen3-VL and its MoE variant, Qwen3-ASR, Qwen3 TTS, and the EAGLE3 and DFlash draft models used for speculative decoding. GGUF is the format llama.cpp users already download, so more of those files can go straight into OpenVINO.

Caveat. This sits on the master branch, not in a release: the latest release is still 2026.4.1 of 1 October. Gemma3n's audio branch needs an extension, GenAI pipeline support for the new projectors is tracked in a separate pull request, and the change adds no Omni speech or video generation or voice cloning.
