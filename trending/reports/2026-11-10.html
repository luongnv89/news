Pick 1 · AI agents / smart home GitHub rank #10 of 11

homeassistant-ai/ha-mcp

Python · License: MIT

What it does. HA-MCP is an MCP server for configuring and automating Home Assistant from Claude, ChatGPT and other AI assistants. Its recommended install is an integration that runs the server inside Home Assistant itself; an add-on, Docker, PyPI and local stdio are alternatives.

Why it is interesting — editorial. First time on our list. Version 9.0.0 (28 October) turned the in-process integration into a full install with locked-down defaults, an access on/off switch and allowlisted OAuth callbacks, and the README says Home Assistant 2026.11 lists it in the built-in Marketplace, so no custom repository is needed. v9.1.2 followed on 8 November.

Caveat. The server acts as a Home Assistant administrator, and the README itself warns that a long-lived token works from anywhere if it leaks; it suggests a dedicated account instead. An AI client can then change automations and real devices, the in-process server needs Home Assistant 2026.8 or newer, and dev builds ship several times a day. We did not install it.

Pick 2 · AI agents / memory GitHub rank #6 of 11

garrytan/gbrain

TypeScript · License: MIT

What it does. GBrain is a self-hostable memory layer for AI agents, written by Y Combinator CEO Garry Tan. It stores facts with their sources, supports corrections and withdrawals, and shares that memory across agents over MCP, starting with keyless keyword search and adding semantic search, cited synthesis and a typed knowledge graph.

Why it is interesting — editorial. First time on our list. Most agent memory tools return chunks; GBrain's README promises a cited answer plus a note on what the brain does not know. It runs on embedded PGlite with no server or model key to start, and the author says it powers his own agents across about 155,000 pages, a claim we did not verify.

Caveat. It changes very fast: 20 tagged releases in the 24 hours before our check, and it needs Bun 1.4.4 or newer. The README notes that configured cloud embedding and synthesis providers receive your text and that Markdown export is not a full backup. The quick install pipes remote scripts into a shell, and gbrain.io is a paid hosted option. We did not install it.

Pick 3 · Developer tools / browser automation GitHub rank #7 of 11

vercel-labs/agent-browser

Rust · License: Apache-2.0

What it does. agent-browser is a native Rust CLI that gives an AI agent a browser it drives one command at a time, reading each page as a compact accessibility snapshot with a ref for every element.

Why it is interesting — editorial. Repeat from 6 November, for a new release. v0.42.0, published early on 10 November, adds experimental saved flows: record a browser task once, then replay it by trying direct HTTP first, then the same request from the page, then the recorded commands. That can make repeat agent tasks far cheaper than re-browsing. The release also centralises session reuse and fixes Safari and iOS sessions.

Caveat. Saved flows are labelled experimental, and replaying recorded requests can break when a site changes or run against its terms of use. v0.42.0 also raises the minimum to Node 22. An agent with a live browser can act on anything that browser reaches, so keep it on a separate profile. We did not install it.

Pick 4 · Finance / LLM application GitHub rank #9 of 11

ZhuLinsen/daily_stock_analysis

Python · License: MIT

What it does. An LLM-driven watchlist analyser for several stock markets (mainland China, Hong Kong, US, Japan, Korea, Taiwan). It pulls quotes, indicators and news, writes a daily decision dashboard and pushes it to WeChat Work, Feishu, Telegram, Discord, Slack or email.

Why it is interesting — editorial. First time on our list. It is a complete, inspectable example of a scheduled LLM pipeline that runs free on GitHub Actions from a fork with repository secrets. v3.34.0 (9 November) refreshes default models and stops Market Light scoring from treating a rising VIX as a rising market.

Caveat. The README's own disclaimer says it is for study and research and is not investment advice. Free data sources are rate-limited and unstable, model and news-search keys may cost money, and the README promotes sponsored model resellers. Its README is mainly in Chinese, with an English version under docs. We did not install it.
