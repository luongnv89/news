Pick 1 · Robotics / physics simulation GitHub rank #8 of 9

google-deepmind/mujoco

C++ · License: Apache-2.0

What it does. MuJoCo (Multi-Joint dynamics with Contact) is Google DeepMind's general-purpose physics engine for robotics, biomechanics and machine learning. It has a C API, Python bindings and a Unity plug-in, and simulates articulated bodies touching their environment.

Why it is interesting — editorial. Version 4.0.0 shipped on 6 November. Its release notes list speculative contacts that stop fast objects tunnelling through thin walls, elasto-plastic springs and deformable bodies that keep a permanent bend, and a split of the Python package into mujoco-core, mujoco-studio and the default mujoco.

Caveat. 4.0 is a major version with several breaking changes: new tendon side-site semantics, the cable plugin and composite element removed, Python 3.10 support dropped. The release notes warn that upgrading the pip package in place needs an uninstall or forced reinstall first.

Pick 2 · AI agents / skill examples GitHub rank #7 of 9

anthropics/skills

Python · License: Apache-2.0 per skill folder

What it does. Anthropic's public collection of Agent Skills: folders of instructions, scripts and resources that Claude loads for a task, plus the Agent Skills specification and a template. It holds 19 skills, from design and testing to the docx, pdf, pptx and xlsx document skills.

Why it is interesting — editorial. This is a repeat with a material change. When we first covered it on 31 October, the four document skills were source-available under Anthropic's terms only. Commit 2c5958e, merged on 6 November, moved docx, pdf, pptx and xlsx to Apache 2.0, so the most complex production skills here can now be studied and reused like the rest.

Caveat. GitHub still detects no repository-wide licence: each skill carries its own LICENSE.txt, and doc-coauthoring has none. The README calls the skills demonstration and educational material whose behaviour may differ from Claude's. Skills include scripts an agent runs, so review them like code.

Pick 3 · AI agents / desktop app GitHub rank #3 of 9

milind-soni/OpenMausBot

TypeScript · License: Apache-2.0

What it does. A desktop chat app for macOS, Windows and Ubuntu where each AI bot is a contact with its own model, computer and connected apps. Bots run on the claude, codex or grok command-line tools already signed in on your machine.

Why it is interesting — editorial. A repeat with material change: since our 30 October pick it has published sixteen releases, v0.1.135 to v0.1.150. Version 0.1.147 added a notes bot that joins Google Meet, Teams or Jitsi calls as a guest and posts a summary, decisions and transcript; others added parallel threads per bot, team sharing and several workspaces.

Caveat. A meeting bot records other people, so participants' consent is needed. Outside a MausBot Cloud plan, transcription needs your own ElevenLabs, Groq or OpenAI key, or a local Whisper model. Cloud computers come from the paid third-party Boat service after a trial, and near-daily releases mean frequent change.

Pick 4 · Developer tools / AI app templates GitHub rank #4 of 9

anthropics/claude-quickstarts

Python · License: MIT

What it does. Anthropic's starter projects for building on the Claude API: a customer-support agent, a financial data analyst, computer-use and browser-use demos, minimal browser and computer toolset drivers, an autonomous coding agent, and a growing set of Managed Agents examples for Slack, Linear, Sentry and more.

Why it is interesting — editorial. It shows working patterns rather than snippets. The newest Managed Agents examples include a Sentry autofix agent that reproduces a bug with a failing test and opens a pull request for human review, with credentials kept outside its sandbox and a hard spend cap, and a knowledge wiki rebuilt on 6 November.

Caveat. Every quickstart needs a Claude API key and paid usage. The README says the toolset examples are not production code, and the macOS computer-use reference controls a real desktop, which it advises running in a VM.
