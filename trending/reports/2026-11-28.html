Pick 1 · AI inference / Developer tools GitHub rank #8 of 16

openvinotoolkit/openvino

C++ · License: Apache-2.0

What it does. Intel's open-source inference toolkit: it converts and optimizes trained models and runs them on CPUs, Intel GPUs and Intel NPUs.

Why it is interesting — editorial. Material change since the 24 November card on GGUF conversion: overnight it merged a vLLM backend built on torch.compile, which vLLM loads as a plugin and which runs on CPU once a deployment selects the openvino compile backend. A separate merge lets its GGUF frontend load Inkling 2 and Inkling 2 Mini GGUF files, vision projector included, with outputs checked against llama.cpp in the pull request's tests.

Caveat. Both changes are on the master branch, not in a release: the latest release is still 2026.4.1 of 1 October. The Inkling pull request itself says PagedAttention does not work yet and GPU decoding is very slow until a follow-up lands; the vLLM path is CPU only, and both pull requests say AI coding agents helped write them. No speed figure here was measured by us.

Pick 2 · Developer tools / Web data GitHub rank #6 of 16

firecrawl/firecrawl

TypeScript · License: AGPL-3.0

What it does. A web scraping and crawling service for AI agents: it turns websites into clean Markdown as a hosted API, a self-hosted server or the single-binary Firecrawl Local.

Why it is interesting — editorial. Material change since the 24 November card, for anyone who self-hosts it: the admin routes and queue dashboard that took the admin key as part of the URL are now off by default. A key in a URL tends to end up in access logs and proxies, and a change merged on 24 November already redacted it from Firecrawl's own logs and made every admin route answer with the key in a header under /admin/ops/, checked in constant time.

Caveat. Self-hosted setups whose monitoring still calls the old /admin/key/ addresses will stop getting answers unless they set BULL_AUTH_KEY_PATH_ROUTES=true or switch to the header routes. This is on the main branch, not in a tagged release, and when the hosted service picks it up was not checked. The project is mainly AGPL-3.0, with MIT SDKs.

Pick 3 · AI / Machine learning education GitHub rank #4 of 16

jingyaogong/minimind

Python · License: Apache-2.0

What it does. A from-scratch course in training a small language model: it writes pretraining, fine-tuning and reinforcement learning out in plain PyTorch for a 64M-parameter model.

Why it is interesting — editorial. Back after our 18 November card because a contributor found that its repetition penalty missed repeated Chinese text: the word splitter behind the penalty in the PPO, GRPO and agent RL scripts counted an unpunctuated run of Chinese characters as one word, so repeated phrases went unpunished. The fix splits Chinese, Japanese and Korean text per character and, by the pull request's own test, leaves English scores unchanged. Training can now also use an optional learning-rate warmup.

Caveat. Reinforcement-learning runs made with the earlier code largely escaped the repetition penalty on Chinese output, and the before-and-after scores are the contributor's tests. A 64M model is a teaching tool, not a capable assistant; the main README is in Chinese, with an English translation.

Pick 4 · AI agents / Developer tools GitHub rank #5 of 16

cursor/plugins

TypeScript · No license detected

What it does. Cursor's plugin specification and catalogue: each plugin is a folder of skills, rules and MCP definitions that the editor's agent can load.

Why it is interesting — editorial. Back after our 18 November card, when the marketplace manifest listed 149 plugins: it listed 160 at our check, with connectors such as FreshBooks, Easyship and Jobber added since. The pstack workflow plugin also gained /reframe, a skill that gives the expert terms and neighbouring fields for what you describe, each with a link it says it opens and cuts if unconfirmed.

Caveat. GitHub detects no license for the repository: the README ends with an MIT line, but there is no root license file, so check each plugin. Connector plugins give an agent access to business data under your account, so review their scopes; one was added and reverted within ten minutes on 25 November. There are no releases or version tags.
