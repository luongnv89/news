Pick 1 · AI agents / Research GitHub rank #10 of 16

mvanhorn/last30days-skill

Python · License: MIT

What it does. An agent research skill: it searches Reddit, Hacker News, GitHub, YouTube, prediction markets and the web for a topic, scores what people engaged with over the last 30 days, and writes a grounded brief.

Why it is interesting — editorial. Material change since the 25 November card, which said its batch of security fixes was not in any release: version 4.7.0 now ships them, and its changelog lists more than twenty security hardenings, from limiting the HTTP client to http and https to keeping secrets out of child processes and error messages. It also adds an optional native Rust core that the pull request says speeds up deduplication and clustering many times over, plus V2EX and, in 4.8.0, Juejin as opt-in Chinese-language sources that need no key.

Caveat. By default a live run now downloads and runs a prebuilt binary from the project's GitHub releases, checked against a SHA-256 list published in the same release, so it guards against corruption, not a compromised release; setting LAST30DAYS_ENGINE=python turns that off. The speed-ups are the maintainer's Apple Silicon benchmarks, not measured by us. Disclosure: an earlier version powers part of The AI Gazette's research step.

Pick 2 · Security / AI agents GitHub rank #1 of 16

elementalsouls/Claude-BugHunter

Python · License: MIT

What it does. A skill bundle for authorized bug hunting and external red-team work: 85 skills and 16 slash commands for Claude Code, built from patterns in 681 disclosed HackerOne reports, with an engine meant to keep each test inside the program's scope.

Why it is interesting — editorial. Material change since the 26 November card, which covered a backslash trick that let a request slip out of scope: overnight the maintainer closed five more fail-open scope holes reported by one researcher, and two more raised by others and by an in-house audit, according to the commits. An out-of-scope IPv6 address written in an unusual form was admitted, API spec paths and a target's own robots.txt could point requests at other hosts, and a comment after a network range silently disabled a deny rule. The runner also has its first PyPI package, claude-bughunter 2.1.0, published from a v2.1.0 tag.

Caveat. This is offensive tooling, for assets you own or are authorized to test. Scope-gate fixes on 24, 25 and 27 November show the gate is a backstop, not a guarantee, and the maintainer says the PyPI package carries only the cbh runner, not the full engine or skills, which still come from a clone or plugin install. The fixes and their severity are the maintainer's own account.

Pick 3 · Mobile development / Compliance GitHub rank #12 of 16

mjmirza/app-store-compliance

Shell · License: OpenRoots Agent License 2.3

What it does. A pre-submission guard for mobile apps: a playbook and shell script that scan an iOS or Android project for common App Store and Google Play rejection causes before you submit.

Why it is interesting — editorial. Material change since the 22 November card on v2.5.0: three patch releases later, v2.5.3 tracks Google Play's 2027 rules for foldables, under which, it says, apps must reach the Adaptive ready tier from April 2027 and target Android 17 from August 2027, plus the global rollout of Android developer verification. A new manual check lists locked screen orientations to confirm, and the installer can now wire its submit-blocking hook into Kiro as well.

Caveat. The licence is the OpenRoots Agent License 2.3, not an OSI open-source licence, with a royalty above USD 20 million in annual revenue. The deadlines are the maintainer's reading of Google's policies, so check them against Google's own pages, and a clear scan is not an approval, as the README itself says.

Pick 4 · Developer tools / Diagrams GitHub rank #9 of 16

cathrynlavery/diagram-design

HTML · License: MIT

What it does. An agent skill that draws diagrams: it writes one self-contained HTML and SVG file per diagram, in your own brand, for Claude Code, Codex, Cursor, Copilot and other hosts.

Why it is interesting — editorial. Material change since the 23 November card on its Git graph type: on 24 November it added print-ready vector PDF export. According to the pull request, a diagram becomes a single-page PDF sized to the drawing, or is fitted onto an A4, A3 or Letter sheet, with text and curves kept as vectors, so it can go straight into an RFC, a paper or a print deck.

Caveat. Export needs Playwright and a Chromium browser installed separately, which the pull request says it will not install for you, and the README's export section still describes only SVG and PNG. The feature is three days old, and the follow-up fixes since show it is still settling.
