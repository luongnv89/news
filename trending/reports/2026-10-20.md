## Picks

### 1. [headroomlabs-ai/headroom](<https://github.com/headroomlabs-ai/headroom>)

*AI agents / developer tools · GitHub rank #7 of 12 · Python · License: Apache-2.0*

**What it does:** A local compression layer for AI agents: it shrinks tool outputs, logs, files, RAG chunks and chat history before they reach the model, as a Python/TypeScript library, a local proxy, an MCP server or a one-command wrapper around agents such as Claude Code, Codex, Cursor and Aider.

**Why it is interesting (editorial):** *It targets a cost most agent users feel: long sessions where logs and JSON tool output eat the context window. Compression runs on your machine, chooses a method per content type (JSON, source code via syntax trees, prose via its own small model), and keeps originals in a local cache so the model can fetch the full text when needed. A headroom unwrap command is documented to undo agent wrapping.*

**Caveat:** Savings figures (for example 60-95% fewer tokens on JSON) are maintainer benchmarks, and the README says short chats, prose and already-dense output see little or no reduction. An anonymous telemetry beacon is on by default (opt out with HEADROOM\_TELEMETRY=off or DO\_NOT\_TRACK=1). Text compression downloads a Hugging Face model, native packages cover only Apple Silicon Macs and Linux (Intel Macs use Docker), some features fall back to simpler methods on x86 CPUs without AVX2, and wrapping changes your agent's configuration. Prompt-injection filtering is reserved for the paid Enterprise tier. Nothing was installed or run.

### 2. [withmarbleapp/os-taxonomy](<https://github.com/withmarbleapp/os-taxonomy>)

*Education / open data · GitHub rank #8 of 12 · JavaScript · License: ODbL-1.0*

**What it does:** An open dataset of what children learn in primary school: 1,591 small teachable topics across eight subjects, linked by 3,225 prerequisite relationships and mapped to curriculum standards such as Common Core, NGSS and the UK National Curriculum. It is plain JSON with schemas and checksums.

**Why it is interesting (editorial):** *A rare non-agent pick and a practical one: most curriculum data is a flat list of standards or locked inside a product, while this is a connected graph you can query to find what a learner must master before a topic. Each topic carries mastery evidence and an age range, and the README documents its multi-layer licensing clearly. It is useful for tutoring tools, learning-path planners or educational research.*

**Caveat:** Licensing is layered: the database is ODbL 1.0 (attribution, and modified databases must stay open), Marble's text is CC BY-SA 4.0, and the curriculum standards file stays under each source's own license (see PROVENANCE.md). Teaching-research records cover only Science and Mathematics (540 topics have none), and the README describes their provenance as an authoring model with a confidence field that is not an independent quality score. Treat it as a draft resource, not vetted pedagogy. No data was downloaded.

### 3. [MadsLorentzen/ai-job-search](<https://github.com/MadsLorentzen/ai-job-search>)

*AI agents / careers / security hardening · GitHub rank #1 of 12 · Python · License: MIT*

**What it does:** A job-application framework built on Claude Code that evaluates postings, tailors CVs, writes cover letters and prepares interviews, running from your own fork and machine.

**Why it is interesting (editorial):** *Material change since our 17 October card: release v1.7.3 (published 19 October, 16:42 UTC) hardens its security model. Per the release notes, skills and agents now get only the tools they need, the shipped settings add deny rules for uploads (curl, wget, scp, ssh, nc) and for reading .env and credential folders that hold in every permission mode, the agents that read job postings can no longer edit or write files, and a new posting guard strips hidden HTML, zero-width and bidi characters and flags instruction-like text before the model reads a posting.*

**Caveat:** These are maintainer-described changes, not an independent audit. The posting guard advises but never blocks, and the release says plainly that the permission layer has limits (see SECURITY.md). Forks must merge the new settings blocks by hand, and LaTeX compile and cleanup now prompt for approval. The tool handles your CV and personal data and sends them to your model provider; parts of its salary and portal tooling are Denmark-specific. Nothing was installed or run.

### 4. [shiyu-coder/Kronos](<https://github.com/shiyu-coder/Kronos>)

*AI research / finance · GitHub rank #12 of 12 · Python · License: MIT*

**What it does:** A family of decoder-only foundation models for financial candlestick (K-line, OHLCV) data. A tokenizer turns price bars into discrete tokens and a Transformer is pre-trained on data the authors say comes from more than 45 exchanges, with forecasting and fine-tuning scripts.

**Why it is interesting (editorial):** *It applies the language-model recipe to market price series rather than text, with small published checkpoints (4.1M to 102.3M parameters) that are realistic to experiment with on ordinary hardware. There is an arXiv paper, the README reports acceptance at AAAI 2026, and a Qlib-based fine-tuning and backtesting pipeline. It is useful for researchers comparing time-series forecasting approaches.*

**Caveat:** Forecasting quality figures are the authors' claims. The README itself calls the backtest pipeline a simplified demonstration, not a production trading system, and nothing here is financial advice. The largest model (499.2M) is not released, weights come from Hugging Face under terms not checked here (the MIT license covers the repository code), and the last push was 13 April 2026, so active maintenance is unclear. No models were downloaded or run.
