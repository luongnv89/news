## Picks

### 1. [HKUDS/DeepTutor](<https://github.com/HKUDS/DeepTutor>)

*Education / AI agents · GitHub rank #9 of 11 · Python · License: Apache-2.0*

**What it does:** An **agent-native learning workspace** you run yourself: chat tutoring, quizzes, guided Mastery Paths, research, visualisations, course study and immersive reading of PDFs, EPUBs and YouTube or Bilibili videos, grounded in knowledge bases built from your own documents, GitHub repositories, documentation sites or an Obsidian vault. It runs as a local web app and CLI, installed from PyPI, from source or with Docker, using the model providers you configure.

**Why it is interesting (editorial):** *First time on our list. Most AI study tools are hosted chat windows; this keeps your materials, progress and **inspectable, editable tutoring memory** in a workspace you control, and it checks understanding rather than only answering. Version 1.6.15 (18 October) added independently graded question groups, grading that separates incomplete from incorrect answers, and bounded memory of a learner's unresolved misunderstandings. A CLI with machine-readable output lets other agents drive it, and the design is described in an arXiv preprint.*

**Caveat:** A large, fast-moving system that needs Python 3.11-3.14 plus Node.js 20 or later, or Docker, and your own LLM, embedding and search providers, whose usage you pay for; the release notes say memory compression has its own model cost. The README's quick start suggests **pasting a setup prompt into a coding agent**, which lets that agent act on your machine, and its file sandbox is only best effort without Docker or a system sandbox. Teaching-quality claims are the maintainers'. We did not install or test it.

**Attention, not endorsement:** GitHub showed “1,598 stars today” as displayed for GitHub's daily window (not an audited rolling 24-hour count). Total stars: 46,603 at the metadata check.

### 2. [elayadesign/ai-design-skills](<https://github.com/elayadesign/ai-design-skills>)

*Design / AI coding · GitHub rank #1 of 11 · Language not shown · License: MIT*

**What it does:** A collection of design skills for AI coding tools: Claude Code, Cursor, Codex, Windsurf and anything that reads a Markdown rules file. It currently holds one skill, landing-page-design, a 19 KB SKILL.md that takes **a landing page from intake questions to a shipped page**: page structure, conversion copy, SEO, and a visual system for type, spacing, corner radius, motion and states, ending in a checklist.

**Why it is interesting (editorial):** *First time on our list, and GitHub's top entry today. Unlike tool-backed design checkers, it is **one plain Markdown file you can read in full** before trusting it, and it installs by copying that file, with no scripts, hooks or downloads in the repository. Its design values (fonts, colours, spacing, motion) sit in one section, so a team can fork it and set its own house style.*

**Caveat:** It is **a single skill so far**: a design-to-motion skill added on 25 October moved to a separate repository two days later, and the redesign skill lives in another. The guidance is one designer's opinions, including a mandatory tagline-reveal section, and adapts parts of the MIT-licensed taste-skill. GitHub shows no language because the repository is Markdown only, and there are no releases or tests. We did not use it.

### 3. [obra/superpowers](<https://github.com/obra/superpowers>)

*AI coding / developer workflow · GitHub rank #4 of 11 · Shell · License: MIT*

**What it does:** An **agentic skills framework and development methodology** for coding agents such as Claude Code, Codex, Cursor, Gemini CLI and Antigravity: skills that walk the agent through brainstorming a design, writing a plan, test-driven implementation, subagent-driven execution and code review, installed as a plugin from official marketplaces or from this repository.

**Why it is interesting (editorial):** *Back on our list after our 17 October card, because v7.0.1 (21 October) changed its core behaviour. Building on the brainstorming rebuilt in v7.0.0, it now reads your project before asking anything and **writes a design doc before building**; the maintainers say this cut skipped docs in one test scenario from 24 of 24 runs to 3 of 24. It also trimmed long skills below Claude Code's 20,000-character cut-off after compaction, after one session lost its five-round fix limit.*

**Caveat:** More questions and design docs add latency and token cost, and the maintainers say they are still tuning brainstorming. The test figures come from their own scenario, not an independent benchmark. Installation differs per harness, the optional visual companion has telemetry you can switch off, and the project **no longer accepts agent-written PRs** for other people's issues unless a maintainer asks. We did not install or test it.
