## Picks

### 1. [CopilotKit/OpenBot](<https://github.com/CopilotKit/OpenBot>)

*AI agents / self-hosted platform · GitHub rank #9 of 11 · TypeScript · License: MIT*

**What it does:** A **self-hosted template for company AI coworkers** from the CopilotKit team. Each bot gets its own browser, files and only the tools an administrator grants; Docker Compose runs the app, API, routine worker and PostgreSQL, and any agent that speaks the open AG-UI protocol (LangGraph, Mastra, CrewAI, Pydantic AI, Google ADK or hand-written) can be plugged in. It ships with a General Assistant and a Knowledge bot, plus example fintech bots.

**Why it is interesting (editorial):** *First time on our list. Most agent products run your work on the vendor's side; this one is meant to be cloned and changed, keeps data in your own PostgreSQL and brings no model of its own. Its central idea is that **every action passes one gateway that decides and records it**, with deny rules under /admin/boundaries and an audit page, so you can see what a bot did to a browser, file or tool server.*

**Caveat:** The README calls it **beta, and a template rather than a product**. It requires a CopilotKit Intelligence project and license (a free plan exists; the local self-hosted evaluation licence lasts 30 days and is a macOS preview), plus your own model key. The example settings run in single-user mode, which admits every request as one administrator, so turn on sign-in before anyone else can reach it. The governance claims are the maintainers'; we did not run it.

**Attention, not endorsement:** GitHub showed “247 stars today” as displayed for GitHub's daily window (not an audited rolling 24-hour count). Total stars: 8,329 at the metadata check.

### 2. [milind-soni/OpenMausBot](<https://github.com/milind-soni/OpenMausBot>)

*AI agents / desktop app · GitHub rank #5 of 11 · TypeScript · License: Apache-2.0*

**What it does:** A desktop chat app (macOS, Windows, Ubuntu 24.04) where **each AI bot is a contact with its own model and computer**. The bots run on the Claude, Codex or Grok command-line tools already signed in on your machine, through a small server on 127.0.0.1 that keeps transcripts and keys in \~/.openmausbot. A bot can use a cloud Linux desktop, a local VM or, after explicit opt-in, your own computer, plus connected apps through Composio.

**Why it is interesting (editorial):** *First time on our list. It is an open-source take on the bot-roster idea behind xAI's Grok Bot and similar closed products, using subscriptions you already pay for rather than a new account. **Shell commands and file edits surface as Allow or Deny cards**, and the README is unusually specific about where control of your own screen is supported, in beta, or disabled (Ubuntu Wayland) for safety.*

**Caveat:** Early software: Ubuntu builds are beta and calls are macOS-only. The cloud computers come from Boat, **a paid service after its trial**, and connected apps need Composio, each with its own account and terms. Bots can create schedules and webhooks without a confirmation step (the chat shows an Undo card), and anonymous usage analytics are on until you switch them off. Letting agents drive a real computer is a security decision; we did not install it.

**Attention, not endorsement:** GitHub showed “1,199 stars today” as displayed for GitHub's daily window (not an audited rolling 24-hour count). Total stars: 7,703 at the metadata check.

### 3. [thedotmack/claude-mem](<https://github.com/thedotmack/claude-mem>)

*Developer tools / AI agent memory · GitHub rank #8 of 11 · TypeScript · License: Apache-2.0*

**What it does:** A **persistent memory plugin for coding agents**, built first for Claude Code and now also installable for OpenCode, Codex through T3 Code, Pi and others. Lifecycle hooks record what the agent does in a session, a model compresses that into summaries stored in local SQLite with Chroma vector search, and later sessions get relevant context back through a search skill and four MCP tools.

**Why it is interesting (editorial):** *First time on our list, although it is a mature project with 105,000-plus stars and frequent releases (v15.6.0 on 29 October). It tackles a real gap: agents forget a project between sessions. The **three-step search (index, timeline, then full details)** is designed to spend tokens only on what is needed; the README's "\~10x token savings" is the maintainer's estimate, not something we measured.*

**Caveat:** It works by **capturing everything your agent does**, so secrets in tool output can end up in its database unless you wrap them in its "private" tags. Some model has to summarize that activity: the installer suggests signing in to a hosted claude-mem observer (30-day free trial, after which it falls back to your Anthropic plan unless you subscribe), or you can choose your own OpenRouter, Gemini or Anthropic access. Cloud sync to cmem.ai is optional. It installs hooks into your agent; we did not run it.

**Attention, not endorsement:** GitHub showed “336 stars today” as displayed for GitHub's daily window (not an audited rolling 24-hour count). Total stars: 105,064 at the metadata check.

### 4. [Donchitos/Claude-Code-Game-Studios](<https://github.com/Donchitos/Claude-Code-Game-Studios>)

*Game development / AI agents · GitHub rank #11 of 11 · Shell · License: MIT*

**What it does:** A project template that turns Claude Code into a **game studio of 49 specialized agents**: directors, department leads and specialists for design, programming, art, audio, narrative, QA and release, with engine-specific sets for Godot 4, Unity and Unreal Engine 5. The README lists 74 slash-command skills, 15 hooks that validate commits, pushes and assets, 14 path-scoped coding rules and 62 document templates.

**Why it is interesting (editorial):** *First time on our list. A single chat session has no structure; this adds design reviews, sprint plans and QA gates, and one rule we like: **a visible change is not done until the game was launched and screenshotted**. The README is also candid about overhead: in the maintainer's own comparison, the build with 30 design documents before any code was ranked last, so a single rigor setting lets you dial the process down.*

**Caveat:** Built for Claude Code only. The three director agents ask for Opus and others for Sonnet, which can raise **usage costs on a metered plan**. The 15 hooks are Bash scripts that run on your commits and pushes and can block some of them, so read them before adopting. The rigor comparison is the maintainer's: it says four games were built but the table shows two. It writes no game by itself; we did not install it.

**Attention, not endorsement:** GitHub showed “353 stars today” as displayed for GitHub's daily window (not an audited rolling 24-hour count). Total stars: 29,601 at the metadata check.
