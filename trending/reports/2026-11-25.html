Pick 1 · AI agents / design tools GitHub rank #11 of 16

google-labs-code/stitch-skills

TypeScript · License: Apache-2.0

What it does. Agent skills for Google Stitch, an AI design tool: they let a coding agent generate and edit screens, extract a DESIGN.md design system, and turn Stitch designs into React, React Native or shadcn/ui components.

Why it is interesting — editorial. Material change since the 16 November card, which noted no push since August: work has resumed, and on 24 November the extract-design-md skill gained a live-URL mode. When only a website's address is known, it renders the page in a local headless Chrome, reads its colours, fonts, spacing and button and card styles, and writes them up as a design system, with no API key or third-party extraction service.

Caveat. The skills need the Stitch MCP server and a Stitch account, so design data goes to Google's service, and the README says it is not an officially supported Google product. Live-URL mode needs Node.js with Puppeteer, which the skill installs in a temporary folder if missing, and its own notes say treat everything read from the page as untrusted.

Pick 2 · AI agents / Site reliability GitHub rank #13 of 16

Tracer-Cloud/opensre

Python · License: Apache-2.0

What it does. An open-source AI agent for site reliability: it investigates CI/CD failures and production incidents by pulling evidence from the tools a team already runs, such as Kubernetes, CloudWatch, Grafana, Datadog and GitHub.

Why it is interesting — editorial. Material change since the 23 November card, which covered its new bridge for any MCP server: release v0.1.2026.11.25 ships presets for the vendors' own MCP servers. Setup now offers Grafana, Datadog, PagerDuty and AWS (CloudWatch, ECS, EKS or Prometheus) by name and asks only for a few answers, and Sentry and PostHog connections now appear to the agent as typed tools behind its approval gates.

Caveat. The project is still a public alpha. The pull request says PagerDuty and EKS run with read-only defaults, ECS with writes disabled, and Grafana read-only only when set up that way; each preset still needs real API keys or tokens for those services, and the README says product analytics and Sentry error reports are opt-out.

Pick 3 · AI agents / research GitHub rank #10 of 16

mvanhorn/last30days-skill

Python · License: MIT

What it does. An agent research skill: it searches Reddit, Hacker News, GitHub, YouTube, prediction markets and the web for a topic, scores what people engaged with over the last 30 days, and writes a grounded brief.

Why it is interesting — editorial. Material change since the 22 November card on v4.6.0: 45 pull requests merged since, 21 of them titled as security fixes. They restrict the HTTP client to http and https, add checks against requests to private network addresses, stop secrets leaking into child processes and error messages, and harden the Reddit and X search paths.

Caveat. None of this is in a release yet: the latest tag is still v4.6.0, so installed copies do not have it. The pull requests say they were prepared with coding-agent help, and dozens of changes across the engine in two days carry their own regression risk. Disclosure: an earlier version powers part of The AI Gazette's research step.
