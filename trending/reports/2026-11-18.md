## Picks

### 1. [jingyaogong/minimind](<https://github.com/jingyaogong/minimind>)

*AI / machine learning education · GitHub rank #14 of 15 · Python · License: Apache-2.0*

**What it does:** A from-scratch course in building a small language model: native PyTorch code and open data for every stage, from tokenizer and pretraining through fine-tuning, DPO, GRPO-style reinforcement learning and distillation, ending in a 64M-parameter chat model.

**Why it is interesting (editorial):** *Most LLM tooling hides training behind a few library calls, while MiniMind **writes the core algorithms out in plain PyTorch** so each step can be read and changed. Its models stay compatible with transformers, llama.cpp, vLLM and Ollama, and the README puts the smallest one at about 1/2700 the size of GPT-3.*

**Caveat:** The headline two hours is, by the README's own note, **one epoch of the SFT stage on a single NVIDIA 3090**, not the whole pipeline, and the RMB 3 figure is the matching GPU rental cost; both are maintainer claims. A 64M model is a teaching tool, **not a capable assistant**, and the main README is in Chinese with an English translation.

**Attention, not endorsement:** GitHub showed “192 stars today” as displayed for GitHub's daily window (not an audited rolling 24-hour count). Total stars: 66,240 at the metadata check.

### 3. [Tencent/LoopForge](<https://github.com/Tencent/LoopForge>)

*AI agents / software delivery · GitHub rank #4 of 15 · Go · License: MIT*

**What it does:** A self-hosted workspace from Tencent for shipping software with coding agents: a chat bot opens Docker sandboxes with your repositories, delegates to project roles and opens pull requests, and proven workflows become SOPs of agent, script and human-approval steps.

**Why it is interesting (editorial):** *Back three days after our 15 November card because **version 0.4.0 (17 November) is a security-relevant release**: its notes list keeping credentials out of repository clone URLs, confining agent CLI config writes to the home directory, and redacting agent CLI keys in SOP sandboxes. It also adds SSH repositories with per-host user keys and editing a run's workspace while agents work.*

**Caveat:** It is still **pre-1.0 software**: 0.3.9 will never get a final release, and existing installations must apply new database migrations themselves. It runs as a Docker stack with MySQL, each executor needs its own model credentials, and the security fixes are the maintainers' description, not something we audited.

### 4. [obra/superpowers](<https://github.com/obra/superpowers>)

*AI coding / developer workflow · GitHub rank #9 of 15 · Shell · License: MIT*

**What it does:** An agentic skills framework and development method for coding agents: a library of skills that walks an agent through brainstorming, planning, test-driven implementation and review, installed separately for Claude Code, Codex, Cursor, Copilot CLI and other harnesses.

**Why it is interesting (editorial):** *Back on our list after our 28 October card because v7.0.2 (3 November) **changes how brainstorming asks questions**: it asks only when the answer would change what gets built, asks why first, and offers options with a recommendation.
