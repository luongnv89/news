Pick 1 · Mobile development / compliance GitHub rank #12 of 16

mjmirza/app-store-compliance

Shell · License: OpenRoots Agent License 2.3

What it does. A pre-submission guard for iOS and Android apps: a playbook and shell script that scan a project for common App Store and Google Play rejection causes before you submit.

Why it is interesting — editorial. Material change since the 20 November card: release v2.5.0, published at 00:21 UTC today, adds a readiness file for checks a code scan cannot prove, such as a working demo account, review notes and account deletion on a real device. Each report now opens with the date range of its rule pack and prints a STALE warning when even its newest source is more than 60 days old.

Caveat. The licence is the OpenRoots Agent License 2.3, not an OSI open-source licence, with a royalty above USD 20 million in annual revenue. A clear scan is not an approval, as the README itself says, and the installer edits hook settings in several AI coding tools.

Python · License: MIT

What it does. A skill bundle for authorized bug hunting and external red-team work: 83 skills and 15 slash commands for Claude Code, also loadable by other agents, built from patterns in 681 disclosed HackerOne reports.

Why it is interesting — editorial. Caveat. This is offensive tooling, for assets you own or are authorized to test. There is no new tagged release since v2.1 of June, so these changes sit only on the main branch, and the 'battle-tested' claims are the maintainer's.

Pick 3 · AI agents / research GitHub rank #10 of 16

mvanhorn/last30days-skill

Python · License: MIT

What it does. An agent research skill: it searches Reddit, Hacker News, GitHub, YouTube, prediction markets and the web for a topic, scores what people engaged with over the last 30 days, and writes a grounded brief.

Why it is interesting — editorial. Material change since the 17 November card: three releases in three days, v4.4.0 to v4.6.0. Version 4.6.0 adds a TikTok and Instagram fallback that needs no paid API key, using web search discovery and yt-dlp, while v4.4.0 was a batch of fixes, several of them for privacy. Disclosure: an earlier version of this engine powers part of The AI Gazette's own research step.

Caveat. The wider sources still rely on your own API keys or logged-in browser sessions, and v4.5.0 changed how browser cookies are extracted, which gives an agent access to those accounts. Engagement measures attention, not truth.
