### 1. [openvinotoolkit/openvino](<https://github.com/openvinotoolkit/openvino>)

*AI inference / developer tools · GitHub rank #8 of 16 · C++ · License: Apache-2.0*

**What it does:** Intel's open-source inference toolkit: it **converts and optimizes trained models** from PyTorch, TensorFlow, ONNX, PaddlePaddle and JAX and runs them on CPUs, Intel GPUs and Intel NPUs, with C++, Python, C and Node.js APIs.

**Why it is interesting (editorial):** *It is a mature way to run vision, speech and language models on ordinary laptops and edge boxes without a CUDA card, and the separate **GenAI API targets LLM pipelines**. The latest release, 2026.4.1 of 1 October, broadens LLM attention support in the ONNX frontend and hardens model and compiled-blob import against malformed inputs.*

**Caveat:** Its accelerator paths are **tuned for Intel hardware**: GPU and NPU support means Intel integrated and discrete GPUs and Intel NPUs, and the release notes list NPU crashes with certain Intel driver versions. Speed-ups are the maintainers' claims; measure them on your own models.

**Attention, not endorsement:** GitHub showed “217 stars today” as displayed for GitHub's daily window (not an audited rolling 24-hour count). Total stars: 11,833 at the metadata check.

### 2. [toeverything/AFFiNE](<https://github.com/toeverything/AFFiNE>)

*Productivity / knowledge base · GitHub rank #14 of 16 · TypeScript · License: MIT (backend: AFFiNE EE licence)*

**What it does:** A local-first workspace for notes and whiteboards: **docs, canvas and databases share one editor**, so any block can sit on an edgeless canvas, and it can be self-hosted as an alternative to Notion and Miro.

**Why it is interesting (editorial):** *Your data stays on your own disk first, with real-time sync and collaboration on web and desktop clients, and the self-host guide lets a team keep the whole workspace on its own server. Few open tools merge long-form documents and a free-form whiteboard this closely.*

**Caveat:** The licence is split: the client is MIT, but the **backend server carries an Enterprise Edition licence** that ties production use to AFFiNE's subscription terms. The AI features are a hosted AFFiNE service, recent builds are canary and beta tags, and the last stable release, v0.27.4, dates from 18 August.

**Attention, not endorsement:** GitHub showed “676 stars today” as displayed for GitHub's daily window (not an audited rolling 24-hour count). Total stars: 75,927 at the metadata check.

### 3. [XiaoYouChR/Ghost-Downloader-3](<https://github.com/XiaoYouChR/Ghost-Downloader-3>)

*Desktop utilities / downloads · GitHub rank #15 of 16 · Python · License: GPL-3.0*

**What it does:** A cross-platform desktop download manager: one app handles **HTTP, BitTorrent, FTP, M3U8 and DASH streams**, with a browser extension that hands page media to the app and a ghd command line for scripted downloads.

**Why it is interesting (editorial):** *It runs on Windows, macOS, Linux and Android, offers an aria2-compatible RPC API for other tools, and lets you change a download's URL, headers or proxy mid-transfer without losing progress. The 4.5.11 release of 20 November added German, French, Indonesian, Italian and Korean translations.*

**Caveat:** The README advertises **real-browser TLS fingerprints to slip past anti-bot checks** and opens with a paid residential-proxy sponsor, and its YouTube and Bilibili support can conflict with those sites' terms and with copyright; download only what you have the right to. The maintainer says updates will slow down.
