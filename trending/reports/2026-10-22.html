Pick 1 · Business software / developer platform GitHub rank #8 of 11

twentyhq/twenty

TypeScript · License: AGPL-3.0 with exceptions (see LICENSE)

What it does. An open-source CRM (customer relationship management) platform pitched as an open alternative to Salesforce: companies, people, deals, custom objects and views, workflows and AI agents, used as a hosted cloud service or self-hosted with Docker Compose.

Why it is interesting — editorial. First time on our list, and a business application rather than another coding agent. Twenty treats the CRM as code: the README shows objects, fields and views defined in TypeScript with its SDK and published to a workspace from a CLI, and the repository ships official agent skills for building Twenty apps. Release v2.50.0 (21 October) added AI summaries of Microsoft Teams call recordings and per-seat workspace credits.

Caveat. Licensing is mixed: the LICENSE file puts most code under AGPLv3 with an added exception for apps built on its interfaces, marks some files as commercially licensed Enterprise code, and puts the SDK and UI packages under MIT, so check which parts you rely on before self-hosting or modifying it. Releases come every few days, and both v2.49.0 and v2.50.0 list breaking changes (app permissions, AI credit accounting). AI features consume credits. Self-hosting means running and securing a database full of customer data.

Pick 2 · AI agents / developer tools GitHub rank #10 of 11

akitaonrails/ai-memory

Rust · License: MIT

What it does. A self-hosted long-term memory server for coding-agent command-line tools: it captures sessions through hooks and MCP, keeps a plain Markdown wiki as the source of truth, and passes handoffs between different agent tools.

Why it is interesting — editorial. A repeat from our 18 October card (which cited v3.1.1), re-featured for release v3.2.0, published on 22 October. According to its changelog, session start now points to a session that was cut off by a quota limit, crash or closed terminal, so the next agent can continue where the work stopped. It also adds first-party Qwen Code and Hermes Agent integrations, search for Chinese, Japanese and Korean text without a language model, and a bounded local importer for PDF, DOCX, PPTX and XLSX documents.

Caveat. It installs hooks into your agent tools and keeps captured prompts and work in an always-on server, so decide what may be captured before team use. The README's Docker quick-start runs without authentication (bound to loopback only). Native Windows is still marked experimental. GitHub's compare view lists 461 commits between v3.1.1 and v3.2.0, so expect churn. Integration claims are the maintainer's and were not tested here.

Pick 3 · Developer tools / databases GitHub rank #7 of 11

supabase/supabase

TypeScript · License: Apache-2.0

What it does. The main repository of Supabase, a Postgres development platform that bundles a database with authentication, auto-generated REST and GraphQL APIs, realtime subscriptions, file storage, edge functions and a vector toolkit. Several of those services live in their own repositories.

Why it is interesting — editorial. First time on our list, and a mature, practical pick for app builders. Instead of a proprietary backend, each feature sits on a standard open-source piece: Postgres for data, PostgREST for the API, and Supabase's own Realtime, Auth (GoTrue) and Storage services. Your data stays in plain Postgres, and the same stack can be used as a hosted service or self-hosted.

Caveat. Its Trending spot is not tied to a release: the newest monthly update tagged in this repository dates from 7 August, and we could not establish why it is trending today. Self-hosting means running several services yourself, and some features are hosted-only or paid (the August notes put Pipelines on paid plans). The repository has over 1,100 open issues and pull requests. Licenses of the separate component repositories were not each checked.
