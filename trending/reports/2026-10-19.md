### 1. [ruvnet/ruflo](<https://github.com/ruvnet/ruflo>)

*Agent orchestration / security defaults · GitHub rank #5 of 13 · TypeScript · License: MIT*

**What it does:** An agent coordination layer (meta-harness) for Claude Code and Codex, with CLI and MCP tools, persistent memory, multi-agent swarms, hooks, a daemon and a browser console.

**Why it is interesting (editorial):** *Material change since our 17 October card: release v3.57.0 (published 17 October, 22:38 UTC) changes risky defaults. Per its release notes, init no longer writes a full-access, never-ask Codex config by default; it now writes workspace-write sandboxing with on-request approval, and full trust needs an explicit flag. The loopback MCP bridge now checks Host and Origin headers to block requests from arbitrary web pages (DNS rebinding) when no auth token is set.*

**Caveat:** These are maintainer-described fixes, not an independent audit. Existing permissive .codex/config.toml files are deliberately left in place, so earlier installs stay permissive until changed by hand. The README still says mods run with your account permissions and are not sandboxed, and the full setup installs hooks and a background daemon. Nothing was installed or run.

**Attention, not endorsement:** GitHub showed “513 stars today” as displayed for GitHub's daily window (not an audited rolling 24-hour count). Total stars: 76,683 at the metadata check.

### 2. [debpalash/VoiceStudio](<https://github.com/debpalash/VoiceStudio>)

*Local audio AI / mobile · GitHub rank #9 of 13 · Python · License: AGPL-3.0*

**What it does:** A local voice-production app for voice cloning and design, video dubbing, dictation, transcription and audiobooks, with a local API and MCP server for agents.

**Why it is interesting (editorial):** *Material change since our 15 October card: a commit merged on 17 October adds native iOS (SwiftUI) and Android (Jetpack Compose) companion apps as a preview. Per docs/mobile.md, a phone pairs by QR code or PIN with your own VoiceStudio computer or server to drive Speak, Voices and cloning, Dub and Dictate, with no accounts, cloud relay or analytics. The heavy processing stays on the paired machine.*

**Caveat:** Preview only and not in either app store: you must build from source, or sideload an unsigned iPhone build that expires after 7 days on a free Apple ID. On-device models are only planned, and the change is not in a tagged release yet (latest is v0.5.6). Exposing the backend on a network widens access; the docs require HTTPS beyond local or Tailscale addresses. Clone voices only with consent; model and voice rights are separate from the AGPL-3.0 app license.

**Attention, not endorsement:** GitHub showed “2,082 stars today” as displayed for GitHub's daily window (not an audited rolling 24-hour count). Total stars: 76,013 at the metadata check.
